# 뇌지도 교육·사용성 기준 (2026-10-22)

## 목적
아동·보호자·교사·치료사가 **익숙한 생활 장면 하나에서 여러 뇌 기능이 협력하는 모습**을 쉽게 이해하도록 돕는 교육용 참고 자료다. 뇌 부위 이름 암기, 좌뇌형/우뇌형 판별, 진단, 신경망 정확한 재현, 특정 뇌 부위 강화·치료효과 주장, 시험형 퀴즈 제작이 목적이 아니다.

## 사용자별 성공 기준
- **읽기가 어려운 아동:** 장면(아이콘) 선택 후 뇌 그림에서 색과 숫자가 바뀐다는 것을 볼 수 있고, 해당 번호를 역할 카드와 일치시킬 수 있다. 활동 수행이 말이나 쓰기에 제한되지 않는다. 글을 이해하지 못하면 동행인이 짧게 읽어준다. 그림만으로 완전한 뇌 기능 설명을 보장하지 않는다.
- **보호자:** 한 행동에 여러 뇌 영역이 관여함을 이해하고 특정 행동의 어려움을 특정 부위의 문제로 단정하지 않는다.
- **교사·치료사:** 실제 생활 장면, 대표 역할, 기본 지도와 관련 설명을 빠르게 연결하되 진단·평가 도구로 사용하지 않는다.

## 인터랙션의 단일 흐름
1. **장면 선택**: 8개 기존 장면 중 하나. 새 게임, 새 치료 과제, 자동 재생 없음. 아동의 경험과 직접 연결되는 생활 장면을 선택한다.
2. **먼저 행동·과정, 나중에 뇌 부위**: 생활 장면에 필요한 과정 3가지를 짧은 행동어와 기호로 표시한다. 부위의 번호·이름은 **부가 정보**로만 제공하며, 뇌 부위 이름을 외우게 하지 않는다. 상호작용 가능한 SVG의 여섯 부위와 기존 색·번호를 유지하되, 사용자 피드백에 따라 부위 윤곽과 표면을 직접 다시 그린 교육용 그림을 사용한다.
3. **과정 선택 → 시각적 연결**: 세 가지 과정 중 하나를 선택하면 그림의 대표 관련 부위 하나를 번호·명칭·밝기 대비로 강조한다. 선택하지 않은 뇌 영역도 지도에 남겨 두지만 시각적 주목도를 낮춘다. 과정의 의미를 큰 글자로, 부위의 이름·번호는 작은 참고 문장으로 배치한다. 총 24개 간단한 일상 설명을 제공하며 진단용 지표로 쓰지 않는다.
4. **부위별 참고는 접어서 보이기**: 기본은 생활 장면 학습만 표시한다. 전문가·보호자가 자세히 알고 싶을 때만 6개 부위 목록을 펼친다. 뇌 SVG 부위를 직접 클릭해도 목록과 개별 설명이 열린다. 닫으면 이전 장면과 마지막 과정으로 복귀하며 포커스도 눈에 보이는 버튼으로 이동한다. 심화 설명·1차 출처는 별도로 펼친다.

## 콘텐츠 경계
- 관련 역할 3가지와 현재 집중한 부위 1가지는 **설명에 편리한 대표 예시**일 뿐 실제 뇌 활성 지도가 아니다. 연하게 보이는 부분이 꺼져 있다는 뜻도 아니며, 한 행동에 많은 뇌 영역이 함께 관여한다. 숨쉬기 등에 중요한 뇌줄기는 장면 목록에서 빠졌더라도 계속 관여한다.
- 인지, 언어, 운동 등은 분산된 네트워크와 환경·과제 맥락에 의해 달라진다.
- 관찰만으로 개인의 뇌 기능, 장애 여부, 성장·치료효과를 판단하지 않는다.
- 역할별 신경과학 설명은 기초 개념이며 의학적 진단서·임상 중재 매뉴얼이 아니다.
- 화면 표시를 억지로 다르게 보이게 하려고 부위 조합을 추가하거나 변경하지 않는다.

## 디자인·접근성 기준
- 기존 모아 캐릭터는 바꾸지 않는다. 뇌 그림은 사용자 승인에 따라 직접 작성한 SVG로 재설계하되, 6부위 색·번호와 기능 정보·상호작용을 유지한다. 본문 Pretendard/SUIT, 소제목 MaruBuri SemiBold, 포인트 나눔손글씨 유지.
- **선택 버튼과 바뀌는 그림을 인접 배치한다**: 데스크톱은 과정을 왼쪽, 뇌를 오른쪽에 배치하고 모바일은 한 흐름으로 쌓는다. 기존 6부위 카드로 생기는 중복과 빈 공간은 기본적으로 제거한다.
- 선택 버튼은 최소 44px 높이, 키보드·터치·스크린리더 지원, 선택 상태 표시. 숫자·텍스트·색을 병용해 색각 차이를 고려한다.
- 화면에 움직이는 자동 애니메이션·팝업·퀴즈를 추가하지 않는다. 과도한 신규 버튼·중복 콘텐츠를 만들지 않는다. 글이 어려운 사용자는 기기 내장 음성을 선택적으로 사용할 수 있지만, 자동재생·녹음·외부 API는 없다.
- 범위는 뇌지도에만 한정하고 다른 게임·홈페이지 공통 스타일은 변경하지 않는다.

## QA 및 검증 경계
- 코드·브라우저: 8개 장면×3개 과정 24회 클릭, **한 과정만 선택되며 한 뇌 영역만 강조됨**, 과정명과 보조 부위명 구별, 비선택 부위가 여전히 보이는지, 라벨 잘림·겹침·불필요한 스티커형 카드가 없는지, 접힌 6개 부위 목록 전환과 복원, 선택형 기기 읽기 지원·미지원 안내, 길 찾기/가방 과정 차이, 좌우뇌·활동 8개 보존, 1440/820/390/320px 글자·터치·넘침 및 Pages 공개 브라우저 확인.
- **자동화 합격 ≠ 실제 아동이 이해함**. 비독자 아동, 읽기 가능한 아동, 보호자, 교사·치료사 대상 소규모 사용성 확인(장면↔그림 연결, 대표 부위가 아닌 다른 영역의 참여 이해, 조작 혼란)을 후속 검증으로 남긴다.

참조 원칙: CAST UDL Guidelines 3.0 (representation/perception, illustrate through multiple media), W3C WAI Cognitive Accessibility (controls and affected content grouping). 원칙만 참고하며 뇌지도의 학습효과가 검증됐다고 주장하지 않는다.

## 2026-10-22 SVG 시각 개편 확인 사항
- 기존 ‘동그란 색면 + 흰 이름표 + 짙은 초록 테두리’의 조합은 정보를 분산시키고 선택 구분을 어렵게 한다는 실제 피드백에 따라 폐기했다. 예전 생성 시안이 아니라 HTML 내에서 클릭 가능한 SVG를 직접 수정했다.
- 전두엽·두정엽·측두엽·후두엽·소뇌·뇌줄기 총 6개에 부위별 윤곽, 표면 굴곡, 부드러운 명암, 그림 안 이름과 기능을 제공한다. 해부학적 경계는 엄밀한 피질 지도·MRI가 아니라 교육용 단순화다.
- 선택한 과정의 대표 부위는 선명하고 나머지는 옅다. **옅은 영역이 사용되지 않거나 손상됐다는 의미가 아님**을 그림 하단에 명시한다.
- 모바일은 그림 안 라벨이 작아지는 한계를 인정하며 부위 전체 설명을 사용자 선택 시 펼치는 구조를 유지한다. 과정 선택 즉시 선택 영역의 이름을 그림 위 별도 텍스트로 전달한다.
- 검증에는 후두엽처럼 작은 부위를 선택한 화면, 320px 휴대전화, 글자 잘림, 기존 8개 장면×3개 과정, 개별 뇌 부위·좌우뇌·기기 음성 UI 회귀검사를 포함한다.
- 실제 아동의 이해, 실기기의 음성 품질과 조작 선호는 소규모 사용자 확인이 필요하며 CI 성공만으로 인증하지 않는다.
