# 뇌지도 교육·사용성 기준 (2026-10-17)

## 목적
아동·보호자·교사·치료사가 **익숙한 생활 장면 하나에서 여러 뇌 기능이 협력하는 모습**을 쉽게 이해하도록 돕는 교육용 참고 자료다. 뇌 부위 이름 암기, 좌뇌형/우뇌형 판별, 진단, 신경망 정확한 재현, 특정 뇌 부위 강화·치료효과 주장, 시험형 퀴즈 제작이 목적이 아니다.

## 사용자별 성공 기준
- **읽기가 어려운 아동:** 장면(아이콘) 선택 후 뇌 그림에서 색과 숫자가 바뀐다는 것을 볼 수 있고, 해당 번호를 역할 카드와 일치시킬 수 있다. 활동 수행이 말이나 쓰기에 제한되지 않는다. 글을 이해하지 못하면 동행인이 짧게 읽어준다. 그림만으로 완전한 뇌 기능 설명을 보장하지 않는다.
- **보호자:** 한 행동에 여러 뇌 영역이 관여함을 이해하고 특정 행동의 어려움을 특정 부위의 문제로 단정하지 않는다.
- **교사·치료사:** 실제 생활 장면, 대표 역할, 기본 지도와 관련 설명을 빠르게 연결하되 진단·평가 도구로 사용하지 않는다.

## 인터랙션의 단일 흐름
1. **장면 선택**: 8개 기존 장면 중 하나. 새 게임, 새 치료 과제, 자동 재생 없음.
2. **동시에 시각화**: 기존 승인된 뇌 SVG 그대로 사용. 선택 버튼 가까이에서 대표 부위 3곳을 강조한다. 6개 부위의 본래 색·숫자와 대응한다.
3. **짧은 역할 보기**: 같은 색·숫자, 역할에 맞는 그림 단서, 짧은 한국어를 같은 영역에 배치한다. 특히 길 찾기와 가방 챙기기처럼 부위 조합이 같아도 실제 처리 단서가 다름을 시각적으로 표현한다.
4. **선택 설명**: 기존 부위 카드 선택 시 개별 설명을 제공. 설명을 닫으면 이전 생활 장면으로 돌아온다.

## 콘텐츠 경계
- 강조된 3개 부위는 단지 **설명에 편리한 대표 예시**이지 실제 뇌 활성 지도가 아니다. 나머지 부위가 꺼져 있다는 뜻도 아니다. 숨쉬기 등에 중요한 뇌줄기는 장면 목록에서 빠졌더라도 계속 관여한다.
- 인지, 언어, 운동 등은 분산된 네트워크와 환경·과제 맥락에 의해 달라진다.
- 관찰만으로 개인의 뇌 기능, 장애 여부, 성장·치료효과를 판단하지 않는다.
- 역할별 신경과학 설명은 기초 개념이며 의학적 진단서·임상 중재 매뉴얼이 아니다.
- 화면 표시를 억지로 다르게 보이게 하려고 부위 조합을 추가하거나 변경하지 않는다.

## 디자인·접근성 기준
- 동일 시리즈 모아 캐릭터 및 뇌 그림을 재생성하지 않는다. 본문 Pretendard/SUIT, 소제목 MaruBuri SemiBold, 포인트 나눔손글씨 유지.
- **선택 버튼과 바뀌는 그림을 인접 배치한다**: 특히 320/390px의 모바일에서 다른 화면으로 옮겨가지 않아도 관계가 보이도록 한다.
- 선택 버튼은 최소 44px 높이, 키보드·터치·스크린리더 지원, 선택 상태 표시. 숫자·텍스트·색을 병용해 색각 차이를 고려한다.
- 화면에 움직이는 자동 애니메이션·팝업·퀴즈를 추가하지 않는다. 과도한 신규 버튼·중복 콘텐츠를 만들지 않는다.
- 범위는 뇌지도에만 한정하고 다른 게임·홈페이지 공통 스타일은 변경하지 않는다.

## QA 및 검증 경계
- 코드·브라우저: 8개 장면 조합, 두 장면(길 찾기/가방 챙기기)의 상이한 역할 아이콘·문구, 6개 부위 숫자 매칭, 단독 선택/닫기 복귀, 두 탭과 기존 생활 활동 보존, 1440/820/390/320px 화면의 글자·터치·넘침 확인, GitHub Pages 실제 사이트 확인.
- **자동화 합격 ≠ 실제 아동이 이해함**. 비독자 아동, 읽기 가능한 아동, 보호자, 교사·치료사 대상 소규모 사용성 확인(장면↔그림 연결, 대표 부위가 아닌 다른 영역의 참여 이해, 조작 혼란)을 후속 검증으로 남긴다.
