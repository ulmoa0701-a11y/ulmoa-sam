# 모아의 숫자 숲: 교육·게임 통합 설계 기록 (V3)

## 목적과 정직한 표현

- 대상: 초기수학을 처음 접하거나 수량·관계에서 어려움을 겪는 아동. 언어·주의·소근육 차이를 고려한다.
- 목표: **게임에서 수학적 조작을 통해 관계를 경험하고**, 다음 상황에서 스스로 사용하게 돕는 것.
- 이 소프트웨어는 수학 진단도구나 입증된 치료 프로그램이 아니다. '완료', '힌트 받아 해결', '도움 없이 해결', '다른 그림 연습'을 구분한다.
- 코딩 자동 QA 통과는 실아동 학습효과 및 몰입도 근거가 아니다.
- 로그인 없이 개인식별정보를 수집하지 않는다. 진행 요약은 이용 중인 기기 localStorage만 사용한다.

2. IES WWC, *Assisting Students Struggling with Mathematics* (2021): 명시적·체계적 교수, 적절한 표상, 수직선, 수학적 언어 및 문장제. https://ies.ed.gov/ncee/wwc/PracticeGuide/26
3. EEF *Teaching association between number and quantity*: 수량·숫자 연계, 마지막 수가 전체 수량을 뜻함(기수성), 작은 수량 알아차리기. https://educationendowmentfoundation.org.uk/early-years/evidence-store/early-mathematics/teaching-association-between-number-and-quantity
4. CAST UDL Guidelines 3.0 (2024): 여러 방식의 시범과 응답, 단계적인 지원, 다양한 상황에 적용. https://udlguidelines.cast.org/
5. NCII *Error Analysis in Math* (2025): 오류 종류를 관찰하고 지도 방법을 개선하되 원인 진단으로 단정하지 않는다. https://intensiveintervention.org/resource/math-error-analysis
6. Skene et al. (2022), Child Development: 안내가 있는 놀이 연구에서 초기수학에 평균적으로 작은 이점 관찰. 성인 안내 연구를 단독 디지털 게임 효과로 오해하지 않는다. https://doi.org/10.1111/cdev.13730

## V3 학습 사이클 (게임 UX용, 임상 진단 판정 아님)

한 놀이에는 다섯 단계가 있다.

1. 먼저 만나보기(explore): 처음 문제를 해 봄. 독립적 정확도라는 지표에 바로 합산하지 않음.
2. 그림 시범(model): 음성합성 없이 간단한 다른 예시를 보여줌. 도움받은 성공으로 기록.
3. 혼자 해결(independent): 정답 힌트 없이 도전.
4. 다른 모양에서도(transfer): 열매/도형/배경 표상 변형에서 수행. **게임 내 표상 변경일 뿐 실제 생활 전이 증거는 아님**.
5. 다시 확인(review): 다른 조합으로 수행.

오답 2회: 유사 예시 시범. 오답이 반복되는 경우 최후 수단으로 목표 버튼 강조. 이러한 도움을 받고 맞힌 문제는 독립 정답 기록에서 제외. 응답 속도로 감점하지 않음.

**V3의 연습 확인 기준(개발 중 임의 컷오프, 연구 검증 X)**: 총 5번 체험한 뒤 독립 풀이 2번 이상, 다른 그림에서 독립적으로 1번, 마지막 재확인도 독립적으로 성공한 경우 '이번 연습에서 혼자 풀었다'고 표시. **학습 완성이나 치료 효과로 표시하지 않음**. 다른 날과 다른 사물에서 확인이 필요.

난이도: 1차 수량 1~3개, 확인된 세션 1회 이후 최대 5개, 3회 이후 최대 9개 범위. 여러 세션을 반복해 상향. 과거 버전의 단순 '다 눌러서 완료' 기록은 이 기준에 합산하지 않음.

## 학습 내용별 결정적 행동 및 테스트

| 영역 | 수학 목표 | 아직 남은 가장 중요한 검증 |
|---|---|---|
| 일대일 대응 | 친구마다 정확히 하나씩 배분 | **남는 것/부족한 것**을 스스로 판단하는 새로운 장면 |
| 작은 수량 | 1~3을 배열 변경에도 알아차림 | 빠른 알아차림과 하나씩 세는 전략을 다르게 관찰 |
| 수 세기 | 빠짐없는 대응 + 마지막 수를 전체와 연결 | V3부터 수확 후 전체 수량 선택 분리 |
| 비교 | 더 많음/더 적음 | 크기·간격·색 배치와 수량 관계 분리 |
| 숫자 | 물체/점/숫자 표상 연결 | 손가락·점 배열·숫자 위치를 다양화 |
| 5·10 구성 | 전체를 부분으로 만들고 다시 합침 | 조작 이후 숫자만 제시될 때도 이해 |
| 합치기·덜기 | 행동으로 나타난 수의 변화 | 미지수를 바꾸거나 원래 수를 숨긴 상황 |
| 모양·규칙·길이 | 시각 분류·관계·순서 | 교란 변수, 사물 회전, 다양한 실생활 모양으로 확인 |

## 새 게임 장면 아이디어와 수학적 필연성

**1. 도토리 배달 대작전** — 단순히 친구 수만큼 누르는 것이 아니라 제한된 바구니 중 알맞은 묶음을 골라, 부족한 먹이를 찾고, 남는 것을 비교. 같은 수량을 토끼에서 새에게 배달. 필수 목표: 일대일 대응·기수성·수량 비교.

**2. 다람쥐 집의 끊긴 다리** — 막대 2개와 3개를 실제로 이어 필요한 길이 5를 만들고, 다른 조합도 발견. 숫자 5 버튼을 누르는 일보다 합치고 나누는 조작이 목적. 필수 목표: 부분-전체·덧셈·길이.

**3. 여우네 가게의 수상한 주문** — 손님이 숫자 대신 점·손가락·물체 그림 주문서를 내밀고, 아동이 맞는 수량의 물건을 실제로 담아 보냄. 잘못 보내면 부족/남음의 원인을 시각적으로 확인. 필수 목표: 표상 변환·관찰·오류수정.

**4. 색/수량 구별 연습** — 크기·색을 바꿔도 3은 3임을 이해하도록 과제를 구성. 색과 크기 단서를 정답과 혼동시키지 않고 각 목표를 따로 평가.

**5. 그림 없는 새 모험(복습)** — 도토리 대신 조개·돌·컵처럼 상호작용이 바뀌는 새 장면에서 배운 수학적 관계를 적용. 게임 내부 일반화 과제와 실제 생활 적용은 구분.

## 사용자 검증 계획과 반증 기준

- 보호자 설명 없이 5~10분, 텍스트 읽지 못하는 아동도 목표 행동을 이해하는가? 시범 없이 멈추면 안내 실패로 기록.
- 발달·언어·주의 차이와 운동 능력을 고려해 대상별로 반복 점검. 클릭을 잘 못 하는 것을 수학 미이해로 분류하지 않음.
- **문제 맞힌 비율**과 **도움 없는 정답 비율**, 처음 보는 배열에서의 정확도를 따로 본다.
- 하루 뒤/일주일 뒤 같은 개념 유지, 도구와 장소가 바뀐 실제 생활에서의 적용 여부는 별도 평가한다.
- 3번만 무작위로 눌러도 정답이 쉽게 나오면 선택지와 힌트 정책을 재설계.
- 실패·오답에서도 강한 경고음, 게임 탈락, 강제 제한시간 금지. 중단·재진입 가능해야 한다.
- 모둠/진전 지표는 교육용 참고 정보일 뿐 임상적 평가나 연령별 표준화 점수로 표현하지 않는다.

## 다음 개발 우선순위

1. **가장 중요**: 일대일 대응·기수성·부분전체를 연결하는 세 장면의 게임성 고도화, 충분한 다양한 문항 풀 확보.
2. 수직선(0~10, 0~20)과 수의 분해·재구성; 잘 설계된 수직선/10칸 표현의 정확성 점검.
3. 문자·음성 없이도 이해 가능한 실제 시범 모션, 클릭·드래그·키보드/보조기기 등 복수 조작 방식.
4. 아동이 혼자 놀며 알아서 이해한 것으로 착각하지 않도록 첫 사용·보호자 관찰 테스트.
5. 나이 기준이 아닌 실제 수량 이해를 기반으로 단계 분기. 단일 답안의 우연 적중이 진도로 바뀌지 않도록 관리.
