# QA 결과 — 숲 마을 village-v1 (2026-10-22)

범위: `math-garden/village.html`을 Playwright(로컬 서버, 소스 그대로 서빙)로 실제 클릭해 검증. 사람이 직접 브라우저로 플레이하지는 않았다.

| 항목 | 결과 | 비고 |
|---|---|---|
| 모으기(나무/딸기) 반복 클릭이 자원을 정확히 증가시킴 | **통과** | 자동 플레이로 도토리 5회·딸기 3회 클릭 후 `__moaVillageQA()`로 `acorns:5, berries:3` 확인. |
| 탭 전환(모으기/반려동물/짓기)이 서로 간섭 없이 동작 | **통과(버그 발견·수정)** | **초기 구현에 버그가 있었다**: `.panel{display:flex}` 클래스 규칙이 `hidden` 속성보다 우선 적용되어 세 패널이 전부 겹쳐 보이는 문제(스크린샷으로 발견). `.panel[hidden]{display:none}`을 추가해 수정, 재검증 스크린샷으로 확인 완료. |
| 먹이주기 → 허기 게이지·표정·성장 단계 반영 | **통과** | 자원 1개 소모, 허기 게이지(5칸 중 4칸) 상승, 곰이 일시적으로 happy 이미지로 전환되는 것을 스크린샷으로 확인. 성장 단계(5회/12회 임계값) 코드 로직은 확인했으나 12회 도달까지 실제로 반복 클릭해 "꽃 왕관" 등장은 스크린샷으로 재확인하지 않았다. |
| 짓기 — 비용 충분할 때 건물이 배치됨 | **통과** | 도토리 2개로 꽃밭 건설, `buildings:["flower"]`로 상태 반영, 마을 땅에 꽃 이미지가 팝인 애니메이션과 함께 나타나는 것 확인. |
| 짓기 — 비용 부족할 때 에러 없이 거부됨 | **통과** | 오두막(도토리5+딸기2)을 도토리 2개뿐인 상태에서 클릭 → 상태 변화 없음(`buildings` 그대로), 콘솔 에러 없음. 흔들림 애니메이션 코드는 있으나 흔들리는 모습 자체를 스크린샷으로 캡처하진 않았다(타이밍상 짧아서). |
| localStorage 저장/복원 | **통과** | 자원·반려동물 상태·지은 건물까지 전부 갖춘 상태에서 페이지를 새로고침한 뒤 `__moaVillageQA()`로 동일한 값이 복원되는 것을 확인. |
| PC 1280 / 태블릿 768 / 모바일 420 레이아웃 | **통과** | 세 폭 모두 스크린샷 확인, 깨짐·넘침 없음. 모으기 탭과 반려동물 탭만 전수 캡처했고 짓기 탭은 모바일에서만 캡처했다(태블릿/PC 짓기 탭 스크린샷은 안 찍음 — 레이아웃이 같은 flex 패턴이라 리스크는 낮다고 판단). |
| 콘솔/페이지 JS 에러 없음 | **통과** | 전 시나리오(모으기·먹이주기·짓기 성공/실패·새로고침·3개 뷰포트)에서 `pageerror` 0건. |
| `mission.html`(기존 게임) 회귀 없음 | **통과** | `village.js`/`village.css`는 `mission.*` 파일을 전혀 건드리지 않음(diff 확인). Playwright로 mission.html을 열어 "배달 출발" 클릭 후 오버월드 지도(`.overworld`)가 정상 렌더링되는 것까지 재확인, 에러 0건. |
| 글 없이 핵심 루프 조작 가능 | **통과(자원 숫자 예외)** | 모으기/먹이주기/짓기/탭전환/소리 버튼 전부 아이콘. 자원 개수(도토리 N개)만 숫자로 표시 — "셀 수 있는 양"을 보여주는 목적상 의도적으로 유지, `notDone`에 명시. |

## 요약

핵심 3개 루프(모으기/반려동물/짓기)가 자유 순서로 상호 간섭 없이 동작하고, 정답/오답 게이트 없이 자원 부족만 부드럽게 거부되는 것을 확인했다. **점검 중 CSS 버그(`[hidden]` 무시)를 발견해 바로 수정**했다 — 처음 스크린샷에서 세 패널이 겹쳐 보이는 것을 보고 잡아냈고, 수정 후 재검증했다.

**이 상태를 완성품으로 보고하지 않는다.** 한글 콘텐츠·반려동물 종류·건물 다양성·소리 디자인·허기 감소(시간 경과)·15종 허브 연결은 전부 다음 단계로 분리되어 있다(`asset-manifest.json`의 `notDone` 참고). 짓기 탭의 태블릿/PC 스크린샷, 성장 2단계(꽃 왕관) 실제 캡처, 불가 버튼 흔들림 애니메이션 캡처도 못 했다.
