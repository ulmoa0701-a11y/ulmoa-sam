# QA 결과 — mission-v4 1차 체크포인트 (2026-10-22)

범위: 공유(share) 미션의 "함께 연습"(guided) 화면 1개를 PC 1280px·태블릿 768px·모바일 390px에서 Playwright(로컬 서버, `math-garden/` 소스 그대로 서빙)로 실제 클릭해 검증. 사람이 직접 브라우저로 플레이하지는 않았다 — 아래 항목 중 "자동 브라우저 캡처"로 명시한 것은 Playwright 자동화 결과다.

작업지시서 8절 체크리스트 대조:

| 항목 | 결과 | 비고 |
|---|---|---|
| 글자 가려도 나무·바구니·도토리·접시 구별 가능 | **부분 통과** | 나무·바구니·도토리는 통과(스크린샷 확인). **접시는 이번 범위 밖 — 아직 기존 평면 CSS 모양 그대로.** |
| 캐릭터가 승인 레퍼런스와 동일 시리즈로 인식됨 | **곰만 통과** | 곰은 지정된 클레이 스타일로 교체. **토끼/여우/개구리/새는 아직 이전 SVG 그대로라 곰과 그림체가 서로 다르다** — 2차 확장에서 같은 스타일로 맞출 예정. |
| 배경과 전경의 그림체·광원·시점 일치 | **미통과(알려진 차이)** | 숲 배경(`forest-world.svg`)은 평면 일러스트 벡터, 새 오브젝트(나무/바구니/곰)는 글로시 3D 클레이 렌더로 **기법이 다르다.** 전체 색감(따뜻한 갈색/초록 계열)은 부딪히지 않지만 "그림체 일치"를 엄밀히 통과했다고는 할 수 없다. 배경도 같은 스타일로 다시 만들지, 현재처럼 배경은 유지하고 오브젝트만 입체로 둘지 사용자 결정 필요. |
| 나무→바구니→접시 이동 경로 자연스러움 | **미구현** | 클릭 즉시 상태만 바뀌는 기존 방식 그대로이며, 이번에 이동 애니메이션을 추가하지 않았다. |
| 바구니 도토리 수 0~10 정확히 셀 수 있음 | **부분 검증** | 현재 실제 콘텐츠의 최대 수량인 4개까지 PC에서 육안 확인(겹침 없이 구별됨). **5~10개 구간은 실제 콘텐츠에 없어서 테스트하지 못했고, 레이아웃이 그 수량에서도 깨지지 않는지 보장하지 못한다.** |
| 나무 도토리가 이동 후 중복/잔존 없음 | **로직은 통과, 그림은 고정** | state 기반 남은 개수 표시(칩)는 정확히 줄어듦(스크린샷 4→2 확인). 다만 `acorn_tree.png` 자체는 정적 이미지라 실제 남은 개수와 무관하게 그림 속 도토리 개수는 항상 동일하게 보인다 — 가지별 좌표 매핑은 하지 않았다(의도적 범위 제한, manifest에 기록). |
| 도토리가 바구니 안쪽에 들어가고 뚫고 지나가지 않음 | **부분 통과** | PC 1280px에서 바구니 입구 위치에 맞춰 좌표를 보정해 자연스럽게 보임(스크린샷 확인). **태블릿/모바일에서는 비율(%) 기반이라 이론상 같이 움직이지만 축소 화면에서 핸들 밑 여백에 딱 맞는지 픽셀 단위로 재확인하지 않았다.** |
| 잘못 수확·배달 시 되돌리기 가능 | **통과(로직 무변경)** | `undo` 핸들러·상태 로직을 건드리지 않았다. 렌더링된 HTML에 되돌리기 버튼 존재를 확인했다. |
| PC 1280 / 태블릿 768 / 모바일 390에서 깨짐·넘침 없음 | **통과** | 캡처한 화면(환영/과제/과제+도토리 4개/성공) 기준으로 넘침 없음. 다른 모든 화면 상태(비교·구성 개념, 챕터 종료 등)까지 전수 캡처하지는 않았다. |
| 안내문 없이 첫 행동 단서 존재 | **변경 없음(기존 유지)** | 이번 작업이 건드리지 않은 영역. |
| 힌트받은 정답을 독립 수행으로 기록하지 않음 | **통과(로직 무변경)** | `state.flagged`/`hints` 로직 미변경. |
| 기존 시범·진전기록·복습·다른 표현 활동 유지 | **코드상 유지, 화면상 전수 재확인은 안 함** | `demo()`/`chapterEnd()`/`renderPairing()` 등 로직 무변경. compare·make 개념 화면은 이번에 스크린샷으로 따로 확인하지 않았다(아래 "미완료" 참고). |
| 15종 숫자 게임 및 다른 홈페이지 기능 회귀 없음 | **부분 확인** | `math-garden/index.html`(15종 허브)을 Playwright로 열어 JS 에러 없이 렌더링되는 것은 확인했다(폰트 CDN 2건 실패는 이 샌드박스 네트워크 제한 때문이며 코드 변경과 무관). 15종 개별 게임과 사이트의 다른 페이지(생각정원 등)까지 전부 열어보지는 않았다. 변경 파일이 `math-garden/mission.*`과 신규 자산 폴더로 한정되어 구조적 영향 가능성은 낮다고 판단한다. |
| 캡처 첨부 | **통과** | `previews/before_pc.png`, `before_mobile.png`, `after_desktop.png`, `after_tablet.png`, `after_mobile.png`, `after_success.png` — 전부 Playwright 자동 브라우저 캡처. 사람이 직접 플레이한 캡처는 아님. |
| 파일 실제 존재·투명도·크기·경로 확인 | **통과** | `file` 명령으로 PNG/알파 채널 확인, HTTP 200으로 경로 접근 확인. |

## 요약

이번 체크포인트는 작업지시서가 1차로 요구한 "나무·도토리·바구니·곰" 네 가지를 중심으로 통과했지만, **접시·다른 동물·배경 통일·0~10 전체 수량·이동 애니메이션·사이트 전체 회귀 검사는 아직 완료되지 않았다.** 이 상태를 "완료"라고 보고하지 않고 다음 단계로 분리해 둔다.
