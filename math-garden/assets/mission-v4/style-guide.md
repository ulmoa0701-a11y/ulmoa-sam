# 도토리 배달 대작전 — mission-v4 자산 스타일 가이드

작성일: 2026-10-22 · 작성: Claude (작업지시서 기반)

## 스타일 앵커

- **확정 스타일**: "cute 3D clay toy" — 부드러운 매트 재질, 파스텔 톤, 스튜디오 소프트 라이팅, 둥근 실루엣, 투명 배경.
- 이 스타일은 `ulmoa-center-os` 저장소의 "울모아 생각놀이터" 아이콘 세트(모아의 숫자 숲과는 다른 자매 프로젝트)와 같은 계열이며, 사용자가 이번 작업에서 명시적으로 "생각놀이터 아이콘 그림체처럼" 만들어 달라고 지정했다.
- 기존 숲 배경(`forest-world.svg`)과 다른 동물 캐릭터(`woodland-friends.svg`의 rabbit/fox/frog/bird)는 **이번 1차 작업 범위가 아니므로 변경하지 않았다.** 곰(bear)만 새 스타일로 교체했다.

## 제작 경로 (중요 — 예외 승인 기록)

- `CLAUDE.md`와 이번 작업지시서 둘 다 원칙적으로 Canva 사용을 금지한다.
- 1차 벡터(SVG) 시안을 `forest-world.svg`와 동일한 손그림 기법으로 먼저 제작했으나, 사용자가 대화 중 "생각놀이터 아이콘 그림체(클레이 스타일)로 맞춰 달라"고 명시적으로 요청했고, 이는 Canva로만 재현 가능한 스타일이어서 사용자에게 재확인했다.
- 사용자가 **"이번 작업은 Canva 써도 됨 (예외 승인)"**을 명시적으로 선택했다 (AskUserQuestion 응답, 2026-10-22).
- 따라서 이번 mission-v4 자산은 `mcp__Canva__generate-image` + `remove-background`로 제작했다. **이 예외는 이번 작업물에 한정되며, 저장소의 기본 Canva 금지 규칙을 변경하지 않는다.**

## 색/광원/시점

- 광원: 좌상단 소프트 스튜디오 라이트, 부드러운 드롭섀도.
- 재질: 매트 클레이(비반사), 둥근 모서리.
- 팔레트: 도토리 — 갈색/크림(#946239 계열), 나무 — 파스텔 그린 캐노피 + 갈색 줄기, 바구니 — 라탄 베이지/브라운, 곰 — 밝은 브라운 털 + 크림 배.
- 배경: 모든 오브젝트/캐릭터는 투명 배경(배경 제거 완료).

## 네거티브 프롬프트 (모든 생성에 적용)

- no text, no realistic photography

## 수량 표현 방식 (코드 구현)

- 개별 파일을 무수히 만들지 않고, 기본 오브젝트(나무/바구니/도토리 1개) + CSS 포지셔닝으로 0~N개 수량을 조합한다.
- "숲속 나무" 칸: `acorn_tree.png`를 배경으로 깔고, 남은 도토리 수만큼 `acorn_single.png` 칩을 나무 밑동 쪽에 띄운다 (실제 가지 좌표에 정밀히 박아 넣지 않음 — 가지별 좌표 고정은 2차 확장 과제로 남김).
- "내 배달 바구니" 칸: `basket_empty.png`를 배경으로 깔고, 담은 도토리 수만큼 `acorn_single.png` 칩을 바구니 입구(손잡이 아래, 테두리 라인) 위치에 쌓는다. 실제 테두리 좌표는 PC 1280px 화면에서 픽셀 단위로 보정했다.
- 검증: 현재 콘텐츠의 실제 최대 수량(공유 미션 기준 4개)까지 PC·모바일에서 확인함. 10개까지는 아직 실제 콘텐츠에 없어 미검증 (아래 "미완료" 참고).

## 곰 표정 상태

- `bear_waiting.png`: 기본 대기 표정 — 환영 카드, 친구 대기 화면에 사용.
- `bear_happy.png`: 성공 시 양팔을 들고 웃는 표정 — 배달 성공(success) 화면에서만 사용.
- 전환 로직: `mission.js`의 `friend(name, i, happy)` 세 번째 인자로 제어. `name==='bear'`일 때만 PNG 사용, 그 외 동물은 기존 SVG 그대로 유지.
