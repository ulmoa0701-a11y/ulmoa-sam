## 점검 중 발견·수정한 것

**버그(이 파일에서 발견, mission.css에 있던 기존 결함)**: `mission.css`의 `#sound,#restart,#help,#change{display:inline-flex}` 규칙이 `[hidden]` 속성의 `display:none`보다 CSS 명시도가 높아서, 지도/이동/성공/챕터종료 화면에서도 `#help`/`#change` 버튼이 안 숨겨지는 버그를 발견했다. **mission.html 라이브 페이지에서도 동일하게 재현되는 것을 `Locator.isVisible()`로 직접 확인**했다 — 이번 융합 작업과 무관한 선행 버그다. `mission.css`는 이번 작업 범위상 건드리지 않기로 해서, `forest-world.css`에만 `#help[hidden],#change[hidden]{display:none!important}`로 수정했다. mission.css 자체 수정 여부는 별도 결정 필요.

## 여전히 못한 것 (정직하게)

- 짓기 탭에서 실제로 건물을 "구매"하는 것까지는 이번 회차에서 자동화 스크린샷을 안 찍었다 — 보상 지급 후 자원이 충분해진 것(흐림 해제)까지만 확인했고, 클릭해서 실제로 건물이 추가되는 것은 village-v1 QA에서 이미 검증된 동일 코드라 재검증 우선순위를 낮췄다.
- 보상 경제(인플레이션 — 반복 플레이 시 자원이 너무 쉽게 쌓이는지)는 테스트하지 않음.
- 리듀스드모션 시각 재확인은 안 함(코드상 두 원본 파일의 전역 규칙을 그대로 이식했으니 커버는 되지만, 직접 켜고 재확인하지는 않았다).
- 색약 시뮬레이션 재확인 안 함(mission.js 쪽에서 이미 다룬 것과 같은 수준 — flashFeedback 아이콘 모양 구분은 그대로 유지됨).

이 상태를 완성품으로 보고하지 않는다. B~E 모험(다리 복구 등) 신규 콘텐츠, 15종 허브 링크 연결, 보상 경제 밸런스 검증은 전부 다음 단계로 남아있다.

**업데이트(같은 세션, 뒤이은 작업)**: 15종 허브 링크는 연결 완료(별도 커밋), mission.css의 힌트 버튼 버그도 업스트림에서 수정 완료(별도 커밋) — 위 두 항목은 더 이상 미완료가 아니다.

### 여전히 못한 것 (정직하게, 2차)

- 실제 아동 대상 사용성 검증은 전혀 하지 않음(코드/자동화 검증뿐) — 특히 "길이가 다르면 비교가 더 어려워지는지"는 추측이지 관찰이 아니다.
