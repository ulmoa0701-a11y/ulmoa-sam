# 모아의 다섯 정원 V4 — 미공개 실험 시안

이 폴더는 사용자 디자인 검토를 위한 **별도 시안**입니다. 기존 /gardens/ 경로, 34개 게임, 공개 홈페이지를 수정하지 않습니다.

- PC: 풍경형 다섯 정원 전체 지도
- 스마트폰(600px 이하): 가로 이동 없이 다섯 장소를 세로 탐험
- 각 정원에서 한 번에 3개 게임의 경로를 탐색
- 전체 34개 게임 검색 및 정원별 필터
- 기존 게임 URL로 바로 시작하거나 iframe 미리보기
- 브라우저 확대/축소, 키보드 포커스, reduced-motion 고려

## 자산/검증 주의
- 배경은 생성형 컨셉 아트입니다. 그림에 등장하는 임시 캐릭터가 기존 승인 모아 캐릭터와 동일하다는 뜻이 **아닙니다**.
- 기존 승인 캐릭터/로고/친구들 이미지는 UI에서 별도 URL로 호출하며, 실패 시 장식 요소만 숨깁니다.
- 후속 디자인 QA와 공식 브랜드 정본 비교 없이 main 병합 및 Pages 공개를 하지 않습니다.
- 자동 테스트는 탐색/연결/표시 기능 검증이며, 임상 효과나 아동 대상 사용자 검증은 아닙니다.
