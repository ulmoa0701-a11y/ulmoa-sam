# 모아의 다섯 정원 — 걷는 지도 실험판

현재 V4와 기존 게임 34개의 원본을 변경하지 않는 비공개 실험실입니다.

- 화살표/WASD로 모아 이동
- PC/모바일 지도 터치 또는 클릭으로 목적지 이동
- 모바일 화면 방향 버튼
- 정원 앞에 도착하면 Enter 또는 ‘정원 들어가기’
- 정원 간 빠른 이동과 34개 목록 접근은 항상 가능
- 정원 게임은 기존 주소 그대로, 페이지당 3개씩 탐색
- 전체 34개 검색과 다섯 정원별 필터 제공

**현재 기획 검증용**: 3D/호텔 풍경의 최종 디자인이 아닙니다. 기존 승인 모아 그림을 사용하며 화면은 자체 SVG 원화로 구성했고, 캐릭터가 실제로 걷는 조작과 탐색 동선의 적합성을 먼저 검증합니다. 현재 디자인은 공개 홈페이지에 반영하지 않습니다. 아동 실사용 검증과 임상 효과 검증은 별도입니다.
