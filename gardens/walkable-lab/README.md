# 모아의 다섯 정원 — 직접 걷는 정원 (체험판)

기존 V4 및 34개 게임을 그대로 유지하고, **정원 탐험 UI만 선택적으로 체험**하는 독립 화면입니다.

## 가능한 조작
- PC: 화살표 또는 WASD로 이동, 3D 바닥을 클릭해 해당 위치로 이동
- 모바일: 방향키·바닥 터치로 이동
- 원하는 정원까지 걸어가거나, '정원 바로 찾기'에서 장소 선택
- 정원에 도착하면 실제 게임을 3개씩 확인하고 시작
- '전체 게임 34개'는 **기존 게임별 실제 대표 그림**과 검색·정원 필터 제공
- 플레이어는 기존 승인 모아 이미지를 사용하며, 생성형 배경 속 임시 캐릭터를 사용하지 않음
- 동작이 무겁거나 3D가 지원되지 않으면 `?mode=2d`로 간편 지도 이용 가능
- 정원 지도 본판으로 돌아가기: `../v4-preview/`

## 구현
- 정원·나무·연못·건물·오솔길은 코드에서 렌더링한 실제 Three.js 3D 오브젝트입니다.
- Three.js v0.181.0 (MIT), 로컬 벤더링. 외부 유료 API·구독·추적 기능 없음.
- 전체 게임 주소와 게임 프로그램은 변경하지 않습니다.
- 브라우저/WebGL 환경에 따라 장면 렌더링 품질과 속도가 달라질 수 있습니다.
- 모바일·PC에서 3D 렌더링, 이동·검색, 기존 URL 연결을 분리 검증합니다.
- 저사양 대응 2D 대체 모드를 유지합니다.

**이 버전은 사용성 평가용 체험판**입니다. 고품질 3D 호텔풍 최종 배경·정식 걷기 모션으로 확정된 디자인이 아니며, 실제 아동 사용성 및 임상적 효과 검증을 주장하지 않습니다. 기존 공개 화면을 이 버전으로 자동 대체하지 않습니다.
