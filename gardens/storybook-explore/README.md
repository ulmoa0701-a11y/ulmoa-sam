# 모아의 다섯 정원 — 고화질 2.5D 산책형 지도

기존 3D 체험판과 게임 34개 원본을 그대로 보존한 독립적인 고화질 시안입니다.

- 배경: 1672×941 WebP Q92 원화. 풍경만 포함하며 글씨·버튼·캐릭터는 그림에 들어 있지 않습니다.
- 승인된 모아 이미지, 정원 선택 버튼, 게임 진입 버튼 등은 별도 HTML 요소입니다.
- PC: 화살표/WASD 이동, 배경 터치/클릭 이동, 정원 선택 시 자동 이동 후 게임 열기.
- 모바일: 방향키, 바닥 터치, 하단 다섯 정원 바로가기.
- 5개 정원 구분과 기존 34개 게임 URL·검색을 유지합니다. 게임 내부 코드는 수정하지 않습니다.
- 새로운 유료 서비스, API, 쿠키·분석 추적은 없습니다.
- 정원 방문 동선의 접근성을 위한 전체 게임 검색을 제공합니다.

이 페이지는 **시각적·기능적 시안**이며 아동 실사용성이나 임상적 효과를 검증했다는 뜻은 아닙니다. 기존 3D 모드는 `/gardens/walkable-lab/`에서 별도로 유지합니다.
