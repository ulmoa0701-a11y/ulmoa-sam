# 모아의 다섯 정원: 그림 속을 걷는 2.5D 체험판

이 폴더는 기존 3D 산책 지도와 게임 본판을 **대체하지 않는 별도 고화질 탐험 시안**입니다.

- 다섯 공간이 연결된 1672×941 원화(WebP) 및 3344×1882 고밀도 화면용 파일
- 배경 원화 안에는 **문자, 가짜 버튼, 캐릭터가 전혀 없음**. 정원 현판과 선택 버튼은 실제 HTML이며 모아는 기존 승인 캐릭터를 불러옴
- 배경과 화면 요소가 분리되어 있어 클릭, 키보드, 모바일 방향 조작 가능
- 정원 이름을 누르면 모아가 길을 따라 이동하고 해당 공간의 실제 게임(3개씩) 표시
- 전체 34개 게임 검색, 다섯 정원 분류, 승인된 원래 게임별 대표 이미지, 기존 게임 URL 유지
- 모바일에서도 배경을 억지로 늘리거나 화면을 회전·줌하지 않고 **고정 배율의 카메라 이동**만 사용
- WebGL 및 유료 API가 필요 없는 경량 2.5D. `prefers-reduced-motion` 지원
- 추가비용 0원. 원본 GitHub 코드와 기존 페이지는 별도 승인 전까지 보존

## 범위 및 디자인 검수

현재 배경은 원본 생성 풍경이며(정원 지도 자체와 게임 URL은 기존 자료 기반), 현재 버전의 게임 플레이는 브라우저 QA용 체험판입니다. 캐릭터의 보행은 2D 스프라이트 바운스와 좌우 반전으로 표현하며 정식 관절·프레임 애니메이션이 아닙니다. 실제 아동 대상 사용성 조사나 임상 효과 검증을 뜻하지 않습니다.

- 지도 장소: 인지정원 나무집, 생각정원 연못, 학습정원 책방, 음악정원 무대, 마음정원 꽃 쉼터
- 접근성: 정원 바로 찾기 메뉴, 전체 게임 검색, 버튼 44px 이상, 게임별 링크 직접 시작, ESC 닫기
- QA: PC 1654/1280px, 태블릿 768px, 모바일 390/360px에서 캐릭터 이동·정원 입장·34개 필터·이미지 로딩 점검

후속 개선에서는 실제 시리즈 디자인 승인본과 시각적 일관성, 사용자 조작 만족도, 정원별 게임 연관성을 추가 검토합니다.
