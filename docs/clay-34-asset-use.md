# 다섯 정원 클레이 그림 적용 기준 (2026-10-18)

## 출처와 파일
- 제공 원본: 사용자가 구글 드라이브 폴더에 공유한 `ulmoa_icons_export_v2.zip` (216 PNG).
- 서비스용: `assets/moa-clay-34-atlas.webp` (960×960, 약 135 KB, 투명 WebP).
- 게임별 그림 위치와 순서는 `assets/moa-clay-game.js`의 `KEYS` 순서를 따름. 한 줄에 6개씩 배치.
- 원본 zip 및 원래 승인된 모아 캐릭터는 그대로 보존.

## 적용 위치
1. 다섯 정원의 34개 게임 카드: 실제 플레이 미리보기의 오른쪽 상단 보조 아이콘.
2. 생각정원 안의 기존 게임 목록·소개·플레이 제목·완료: 선택한 게임과 연관된 보조 그림.
3. 손동작 게임: 손 모델이나 카메라 판단에 영향을 주지 않는 소개·완료 화면.
4. 구조대·리듬·리코더·호흡 놀이: 제목·선택·안내 주변의 장식적 그림.
5. 준비물·화폐·감정 3종: 소개와 완료 화면의 아이콘.

## 교육·임상 안전 원칙
- 원본 도형/화폐/글자/운지/손가락/정답 선택지의 **판별 속성은 바꾸지 않음**.
- 이미지 요소는 `aria-hidden=true`로 중복 읽기 방지.
- 반응을 유도할 수 있는 불필요한 장식이나 움직이는 효과를 **게임 과제 영역에 넣지 않음**.
- 한 게임의 목표가 한 요소(색·방향 등)에 있으면 새 그림으로 불필요한 단서를 만들지 않음.
- 게임 성공을 치료 효과로 해석하지 않음.

## 시각적 재검수
- 초기 선별품을 점검해 손동작(손), 꽃(잎), 칠하기(팔레트), 물주기(비), 교실(학교), 준비물(상자), 박자(시계), 리코더(악보), 바람박자(풍선), 바람세기(바람), 오래불기(시계) 등 **11개 그림을 해당 활동과 더 잘 연결되도록 수정**함.
- 최종 그림의 주제 적합성과 2차 표적 자극 혼동 여부는 아동별 사용 평가가 남음.

## 저작권/배포
- 이 그림들은 사용자로부터 제공받은 Canva 제작 이미지임.
- Canva 라이브러리의 Free/Pro 요소가 포함되었는지는 추출 이미지와 파일명만으로 확인되지 않음.
- Canva AI에서 원본을 새로 생성한 결과물이라면 Canva의 AI 제품 약관이 적용될 수 있음. 반면 Canva Pro 라이브러리 요소의 원형 독립 재배포에는 제한이 있음.
- 본 프로젝트에서는 완성된 **작동형 학습게임 UI의 일부**로만 사용하며, 개별 아이콘 다운로드/판매 메뉴를 만들지 않음. 제3자 요소 포함 사실이 확인되면 해당 자산을 교체해야 함.
