## 기술적 품질 개선

- 기존 `hands-on.js`에 `hands-on-core.js` 전체 복사본이 또 있어 실제 브라우저와 QA가 서로 다른 엔진을 사용할 수 있었음. 중복을 제거하고 `index.html`에 공통 엔진을 먼저 로드함.
- PC·모바일 터치/키보드 버튼으로 구성, 개인정보 업로드와 외부 유료 서비스 없음.
- 기존 사과 배달, 기초 곱셈, 모든 기존 단원 경로를 삭제하지 않음.
- 자동화된 학습 성취 결과는 표준화된 교육평가·인지검사 결과가 아님.

## QA 기준

1. `node qa/math-concept-fidelity-qa.cjs`: 수학 모델 수백 회 무작위 검증 + 모바일/PC 실제 조작 + 오답 교정/독립 수행 구분.
2. `node qa/math-curriculum-alignment-qa.cjs`: 1~6학년, 12학기, 71단원, 213개 소단원·선수학습·학년 범위 검사.
3. `node qa/grade-math-units-qa.cjs`: 전체 213개 소단원 5단계 회귀 및 360·390·768·1280px 화면 검사.
4. `node qa/math-learning-path-qa.cjs`: 기존 3학년 곱셈 기초게임 및 독립 문제 풀이 회귀.

## 남은 교육적 과제 — 별도 출시 판단

- 6학년 쌓기나무는 **숫자가 표시된 높이 지도를 보고 재구성하는 조작**까지 구현했다. 앞·옆 실루엣만 보고 가능한 다양한 입체도형을 추론하는 고난도 개방형 활동과 실제 아동의 일반화는 아직 검증되지 않았다.
- 분수÷분수는 몫이 자연수인 초급 예시를 우선 다룬다. 몫이 분수인 상황과 역수 곱셈까지 스스로 설명하는 심화 과제는 추후 추가해야 한다.
- 소수÷소수는 나누는 수의 10배·100배 동치 변형을 학습한다. 소수÷자연수, 자연수÷소수, 어림셈 상황 전체를 완료한 것은 아니다.
- 5~6학년 부피·전개도·격자/그래프와 1~4학년 개별 활동은 각 성취기준에 맞는 조작을 계속 고도화해야 한다.
- 아동 실제 관찰은 별도 수행해야 한다: 글을 읽지 않고 시작할 수 있는지, 식·그림을 연결하는지, 새로운 문제에 일반화되는지, 힌트 개입을 구분하는지.
