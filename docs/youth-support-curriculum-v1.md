# 일단 해봄 — 청소년 개별지원 프로그램·운영 기준 v1.0

**작성일: 2026-10-23 / 운영 전 검토용 매뉴얼**  
**적용 가능성:** 청소년 인지·사회적 의사소통·실생활 교육을 위한 치료사 주도 파일럿. 8회기·회기당 약 40~50분은 **운영 설계안일 뿐 효과가 검증된 횟수/처방이 아님**. 개별 특성에 따라 20~50분, 주 1회, 영상/음성/채팅/대면의 비율과 회기를 조정한다. **심리질환 진단·의료적 치료·학교복귀 보장을 제공하지 않는다.**

## 0. 이 서비스가 실제로 하는 일

- 청소년 본인이 **어떤 도움을 원하고, 어떤 방식으로 의사를 표현할 수 있는지** 찾는다.
- 단순 상담/AI 대화 시간이 아니라 **실제 상황의 행동**(질문·의사표현·요청·계획·거절·안전판단)을 목표로 정한다.
- 치료사·인지치료 관련 역량 범위에서 인지·생활·사회적 의사소통 교육을 제공한다. 사회불안장애·선택적 함구·중증 고립 등 전문치료 필요 사례는 정신건강·언어재활 등 **적격 전문가와 협력**한다.
- 학생·보호자·학교 의견이 달라도 학생의 자기결정과 안전을 우선. AI는 선택적 자료·연습 보조 도구이며 학생의 비밀상담 대체가 아니다.

## 2. 표준 8회 운영 단계와 계약/동의

| 초기 적합성 | 0회 (정규 수업 밖) | 위험·서비스 범위·동의·연락 방법 확인 | 일반 문의 안내와 적합성 결정 |
| 기초선 | 1~2회 | 학생 참여 방식 관찰, 질문 조건/목표 행동별 반응 | 기초선 관찰표 + 목표 1~2개 |
| 연습·적용 | 3~4회 | 구조화 연습 → 실제 사람과 실생활 연계 | 회기별 수행·부담·지원 수준 |

| 최종 평가 | 8회 | AI 없이/단서 적게 새 상황 평가, 종결·연장 판단 | 평가 결과·권고 |
| 추적 | 2~4주 후 | 가능한 범위에서 유지 관찰 | 사후 확인 또는 기관 연계 |

**매회 수업 기본 구조(40~50분 예시):** 인사·모드/상태 선택 3~5분 → 지난 실생활 경험 5분 → 오늘 목표 2분 → 핵심 활동 20~25분 → 실제 사람과 연습·다음 행동 계획 5~10분 → 학생 부담/선택권 확인 3분. 부하가 높은 학생은 단축 가능. 수업 내용을 학생 본인의 장문 구술로 보고하도록 강요하지 않는다.

**세션 종료 후 직원업무:** (1) 표적행동의 기회 수 기록 (2) 독립 수행과 도움 수행 분리 (3) 자기평가 부담 0~10 또는 쉬운 시각척도 (4) 실생활 전이 또는 기회 없음 기록 (5) 다음 일정·연계 필요여부 기록 (6) 보호자에게 전달할 범위 확인.

## 3. 제공 방식: 이동·거리 제약에 맞춤

- **온라인 시작형:** 학생의 동의를 받아 채팅·화면공유·음성·카메라를 선택. 마이크·눈맞춤·얼굴 공개 의무 없음. 사용 기술이 실제 대면 기능의 대리 지표가 아님.
- **대면→혼합형:** 초기 대면 1~4회 + 비대면 주 1회 + 필요한 때 대면 재평가를 **옵션**으로 검토. 횟수는 치료 적합성·학생 선호·거리·안전기준으로 결정.
- **장거리 지속형:** 주 1회 비대면, 매 4회 목표 재평가, 월 1회 또는 3~6개월 대면 여부는 개별 결정. ‘6개월 1회 방문이면 충분’하다는 근거 없음.
- **가정/학교 방문:** 현재 기본 상품에 포함하지 않음. 직원 안전, 장소·보호자/기관 동의, 보험·이동비·기록·전문역량 체계 확립 후 별도 검토.
- **해외:** 국가별 규제·미성년자 보호·위기 연락망·시차·학교 언어 환경 확인 전 모집/제공 보장 금지.
- **비동기 채팅:** 수업 사이 보조과제 공유는 가능하지만 실제 운영시간/응답기한을 문서로 정하기 전 무제한 응대 약속 금지.

## 4. 5개 프로그램(8회기 파일럿) — 학생 반응·현장 적용 중심

### C01. 대화와 또래관계

**대상:** 또래와 말 시작·유지, 질문 답하기, 오해 조정이 어려운 초등 고학년~청소년

**목표:** 대면/온라인 실제 사람과의 상호작용에서 자발적 질문·응답·수정요청을 늘리고 부담을 조절

**주의:** 학생이 원치 않는 친구 사귀기 강요 금지, 학교폭력·괴롭힘 먼저 분리

**측정:** 지원 없는 자발적 질문 수, 3턴 이상 유지 비율, 오해 시 수정요청 수, 본인 선택 활동 참여

| 1 | 어디서 막히지? | 관심사 2개를 고르고 치료사와 5번 짧게 교환, 선택형/개방형 비교 | 나에게 편한 대화방법 1개 선택 | 질문별 독립 응답·반응 시간 |

| 8 | AI 없이 다시 하기 | 처음과 다른 사람 또는 새 주제로 대화 평가, 2주 후 점검계획 | 유지하고 싶은 대화방식 선택 | 독립 질문·유지·부담 비교 |

### C03. 말·대면이 어려운 첫 연결

**대상:** 낯선 사람과 말하기·눈맞춤·화상·교실 접근에 부담이 있는 학생 중 안전·전문평가상 이 서비스가 적절한 경우

**목표:** 학생이 선택한 안전하고 지속 가능한 방식으로 의사·거절·도움 요청을 표현하고 실제 사람과 연결

**주의:** 강제 눈맞춤·강제 카메라/발화 금지; 심한 고립·선택적 함구·우울·불안은 전문기관 협력

**측정:** 동의한 참여 방식 수, 자발적 의사표현·거절·요청, 부담 변화, 실제 사람으로의 전이

|---|---|---|---|---|
| 1 | 첫 접촉 선택 | 글·표시·가리키기·음성 중 선택; 보호자 상담과 안전상황 분리 | 다음 시간 사용 방식 스스로 고르기 | 자발적 참여·거부 의사 |
| 2 | 함께 있기 | 질문보다 관심 있는 조작활동을 나란히 수행, 말 강요 안 함 | 집에서 편한 의사 표현 한 가지 시도 | 활동 선택·중단 요청 |
| 3 | 싫어요·쉬어요 | 멈춤/쉬기/도움 요청 메시지·아이콘 만들고 사용해보기 | 동의 범위에서 실제 요청 기회 확보 | 의사 표현 기회·자발성 |
| 4 | 내가 묻기 | 상대 질문에 답하는 대신 선택한 질문을 치료사에게 보내기 | 필요할 때 한 번 질문 문장 준비 | 자발적 질문 또는 비언어 요청 |
| 5 | 안전한 사람 연결 | 치료사와 익숙한 사람 간 짧은 소통, 학생이 방식·시간 선택 | 실생활 대화/채팅 기회 기록, 강요 금지 | 상대 확장 시 부담 |
| 6 | 의사 오해 고치기 | 음성인식 오류·상대 오해를 ‘아니야/다시’로 정정 연습 | 정정해 본 경험 여부 확인 | 자기결정·수정요청 |
| 7 | 가능한 환경 확장 | 학생이 희망하는 온라인/대면·장소·사람 조건 설계 | 환경 조정 한 가지 협의 | 참여 선택과 편안함 |
| 8 | 기초선과 재비교 | 의사표현 방식과 부담, 실제 대화상대 여부 재평가 | 다음 지원 기관/목표 스스로 선택 | 독립성과 지원 필요 수준 |

**수준 조절:** 쉬움 = 그림·2지 선택·1문장 / 중간 = 3지 선택+이유 / 확장 = 새 상황에서 자기 문장·질문·역할교대. **단계를 올라가는 것이 목표가 아니라 기능적 의사 표현과 실제 생활 사용을 목표로 한다.**


### C04. 학교·사회참여 연계

**대상:** 등교 부담·학교상황 의사소통 곤란이 있으나 적격 전문가·학교의 협력체계에서 개별 지원이 적절한 학생

**목표:** 학교에서 안전하고 필요한 도움을 구하고 선택한 참여 행동을 실행하도록 지원

**주의:** 등교거부 치료·노출치료 대체 아님; 괴롭힘·학대 위험 시 노출보다 안전보호 우선; 출석률 약속 금지

**측정:** 안전한 도움 요청 가능 여부, 학교 협력계획 진행, 학생 선택 활동 참여·부담, 필요한 환경 조정 이행

| 회기 | 목표 | 수업에서 실제 하는 일 | 실생활 연결·선택 과제 | 수집할 관찰치 |
|---|---|---|---|---|
| 1 | 무엇이 어려울까 | 학생 시점에서 학교 하루를 안전한/힘든/모르는 장면으로 구분 | 보호자·학교 안전정보 협의(학생 동의 범위) | 환경요인·도움 희망 |
| 2 | 믿을 수 있는 사람 | 학교·가정·기관에서 도움을 구할 대상 선택과 방법 확인 | 연락 대상/문장 1개 준비 | 안전한 지원망 여부 |
| 3 | 학교 상황 표현 | 교실 앞·복도·질문받기 등 구체상황 1개 글·그림·음성 표현 | 상황별 필요한 도움 한 가지 선택 | 상황 설명 가능 방식 |
| 4 | 요청문 실습 | 교사에게 쉬는 공간/과제 조정 등 요청 문장 연습 | 동의된 협력자에게 전달 | 요청 수행·지원 응답 |
| 5 | 정보·추측 분리 | 타인의 시선·말에 대한 확실한 정보와 불확실한 해석 구분 | 예상과 실제를 나중에 비교 | 정보 구분·확인 질문 |
| 6 | 개별 참여 계획 | 전문가·학교와 합의된 안전·참여 계획 중 의사소통 역할 연습 | 현실적 한 행동만 시도 또는 조정 요청 | 참여·회복·부담 |
| 7 | 어려운 날 계획 | 계획대로 안 될 때 연락·휴식·전문기관 도움 요청 방법 | 대체계획을 학생이 선택 | 재조정 가능성 |
| 8 | 협력 재평가 | 학생·보호자·학교 정보의 차이, 안전·관계·참여 점검 | 유지/의뢰/서비스 조정 결정 | 학교환경 개선·기능 변화 |

**수준 조절:** 쉬움 = 그림·2지 선택·1문장 / 중간 = 3지 선택+이유 / 확장 = 새 상황에서 자기 문장·질문·역할교대. **단계를 올라가는 것이 목표가 아니라 기능적 의사 표현과 실제 생활 사용을 목표로 한다.**


### C05. 생활판단·자립 첫걸음

**대상:** 학교 밖/느린 이해 청소년 등 돈·온라인 안전·검정고시·관계 경계·일상계획이 막막한 학생

**목표:** 공식 정보를 찾고 위험 신호를 구별하며 필요할 때 도움을 요청하고 생활 선택을 실행

**주의:** 법률·금융·성폭력·정신건강 전문상담 대체 금지, 성교육은 검증된 자료/전문기관과 협력

**측정:** 공식정보 확인, 위험신호 구분, 도움 요청/거절 표현, 일상 1개 실행

| 회기 | 목표 | 수업에서 실제 하는 일 | 실생활 연결·선택 과제 | 수집할 관찰치 |
|---|---|---|---|---|
| 1 | 지금 필요한 것 | 검정고시·돈·온라인 거래·관계 중 관심 주제 고르고 사전 기능평가 | 내가 알고 싶은 질문 1개 | 필요도·이해 수준 |
| 2 | 정보 출처 찾기 | 공식/광고/친구 말 구분, 교육청·꿈드림 등 공식 안내 찾기 | 공식 링크 하나 저장/확인 | 출처 확인 |
| 3 | 검정고시 첫 단계 | 시험단계·응시자격·지역별 공고 읽기/고르기, 모르면 전문가 연결 | 필요 서류/일정은 실제 공고 확인 | 절차 파악·문의 |
| 4 | 돈 관리 기본 | 필요/원함/여유 구별, 일주일 예산을 쉬운 표로 편성 | 작은 지출을 선택·기록 | 근거 있는 소비 결정 |
| 5 | 온라인 사기 신호 | 비밀번호·인증번호·선입금 요청을 분별, 즉시 멈추기 연습 | 비슷한 상황 위험 신호 찾기 | 거절/도움 요청 |
| 6 | 관계의 경계와 동의 | 사적인 정보·사진·신체 경계, 거절·신뢰할 만한 도움 요청 | 내 경계 표현 문장 고르기 | 자기보호 표현 |
| 7 | 공공기관 이용 | 꿈드림·1388·경찰청 신고 등의 도움 범위 구분, 링크 확인 | 필요한 정보 경로 북마크 | 적합한 기관 찾기 |
| 8 | 실생활 적용 평가 | 새로운 가상 상황에서 안전한 선택 설명 및 생활목표 재설계 | 다음 한 달 필요 도움 지도 | 전이·도움 요청 |

**수준 조절:** 쉬움 = 그림·2지 선택·1문장 / 중간 = 3지 선택+이유 / 확장 = 새 상황에서 자기 문장·질문·역할교대. **단계를 올라가는 것이 목표가 아니라 기능적 의사 표현과 실제 생활 사용을 목표로 한다.**

## 5. 회기마다 실제 기록하는 지표(임상 기록과 별도 운영표 주의)

| 지표 | 규칙/예시 | 기록 주의 |
|---|---|---|
| 표적 행동 기회 수 | 치료사가 제시한 명확한 상황 5회 | 기회가 없으면 0/5가 아니라 기회 없음 |
| 독립 수행 | 힌트·보기 없이 학생이 스스로 표현 | 구어뿐 아니라 학생에게 적합한 AAC·글·제스처 인정 |
| 지원 수행 | 선택지·시범·구조화 질문 후 표현 | 독립 수행과 섞지 않음 |
| 시작·유지 | 자발적 질문 수, 3턴 이상 주제 유지 | 말 수 자체는 성과가 아님 |
| 부담 정도 | 학생 선택 0~10 또는 3단계 시각 척도 | 사전/사후, 거부 의사 존중 |
| 실제 생활 사용 | 사람과의 구체적 상호작용 횟수/기회 여부 | AI 상호작용을 사람과 동일하게 세지 않음 |
| 생활목표 완수 | 계획·시작·점검 완료 수 | 지적 능력 향상 등 과장 금지 |
| 원치 않는 변화 | 수업 회피 증가, AI 집착, 스트레스·안전 문제 | 위험하면 중단/재평가/의뢰 |

**목표 문장 예시:** “4주 내 치료사와의 안전한 대화 기회 5회 중 최소 3회에서, 본인이 선호하는 글·음성 방식으로 새로운 질문을 독립적으로 한 번 제시한다.” / “6주 내 학생이 정한 생활 과제 3개 중 2개에서 계획표를 실제 사용한다.” **이 목표 숫자는 개별 기준선 기반으로 수정하며 보편적인 효과 기준이 아니다.**

## 6. 치료사용 진행 문장(현장 즉시 사용 가능)

- 반응이 없는 학생: “지금은 말을 안 해도 돼. 고르기/글쓰기/쉬기 중 편한 걸 알려줘.” 
- 선택형에서 멈춘 학생: “1번과 2번 중에 가까운 게 있어? 없다면 ‘둘 다 아님’도 괜찮아.”
- 오해 발생: “내가 다르게 이해했을 수도 있어. 바꾸거나 다시 알려줘도 돼.”
- 친구관계 사건: “우리가 확실히 아는 건 뭐지? 아직 모르는 건? 상대의 마음을 단정하지 말자.”
- 학교 부담: “학교에 들어가는 게 어려운 이유 중 안전 문제는 없는지부터 확인하자. 학교와 어떤 도움을 조정할 수 있을까?”
- 불안 고조: “여기까지로 멈춰도 돼. 안전한 방법으로 현재 필요한 도움부터 찾자.”
- AI 사용 시: “이 프로그램은 연습 도구야. 잘못 알아들으면 바로 고치자. 실제 고민·비밀·개인정보는 입력하지 않아.”

## 7. 보호자에게 제공할 운영 설명

첫 안내 시 **대상·목표/제외 기준, 수업시간·형태, 학생 참여 의사, 비용/환불/취소, 보호자 전달 범위, 개인정보/녹화/저장, 위기연계, 무료지원 적격성, 재평가 시점**을 설명한다. 실제 수업료·운영시간은 확정 전이므로 홈페이지에 임의 게시하지 않는다.

보호자 피드백은 **관찰한 사실·현재 목표·필요한 지원·다음 한 가지 실생활 연결** 중심으로 3~5문장. 예: “오늘은 선택지로 자신의 의견을 고르는 것은 가능했지만, 보기가 없을 때는 응답에 시간이 더 필요했습니다. 다음에는 학교에서 필요한 질문을 문자로 준비하는 방법을 연습하겠습니다. 실제 대면 상황에서의 변화는 더 확인하겠습니다.”

## 8. 등록·연장·종결 기준

- **등록:** 실제 목표 구체화 가능 + 서비스 범위 적합 + 학생의 참여 의사 + 필요한 보호·동의 및 안전 체계 + 온라인 환경 적합.
- **보류/의뢰:** 위험 우선, 전문치료 필요, 목표와 제공역량 불일치, 학생의 명확한 거절, 안전·개인정보 요건 미확보.
- **4회 종료 중간판정:** 진행/난이도 조절/매체 전환/목표 조정/타 전문기관 의뢰 중 선택.
- **8회 판정:** 목표 일부 성취, 유지에 필요한 지원, 실제 생활 적용 확인. 장기 이용을 유도하기보다 자기조절·연계 가능성을 평가.
- **후속 지원:** 필요 시 월 1회 점검 또는 격주·주 1회로 조정할 수 있으나 횟수의 우월성 근거 없음. 2~4주 후 유지 측정.

## 9. 실무용 템플릿(비식별 코드만)

**초기 평가:** 접수코드 / 선택한 모드 / 학생 목표(비식별 행동) / 안전·동의 상태(완료 여부만) / 지원 필요 수준 / 목표행동 기초선.

**회기 기록:** 접수코드 / 날짜 / 프로그램코드 / 회기번호 / 모드 / 오늘 목표코드 / 기회 수 / 독립 수 / 도움 수 / 부담 전후 / 실생활 시도 여부 / 다음 행동·담당 / 다음 확인일. **서술형 사건·진단·이름은 공개 운영표 금지.**

**중간·종결 평가:** 처음과 같은 조건에서 비교하고, 실제 다른 사람과 새 상황에서의 수행을 확인할 것. AI 조건만 점수가 오른 것은 일반화 성공으로 보고하지 않음.
