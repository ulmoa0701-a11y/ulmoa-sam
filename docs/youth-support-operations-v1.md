# 일단 해봄 — 청소년 지원 운영 매뉴얼 v1

2026-10-23 · 범위: **일반 정보 제공과 청소년 인지·의사소통 지원의 초기 운영**. 위기전문 상담·의학적 진단·공공기관 대체 서비스가 아님.

## 1. 시스템 구성과 책임

| 기능 | 위치 | 개인정보 허용 여부 |
|---|---|---|
| 청소년 정보·선택지·상황연습 | `support-first/`, `support-first/try/` | 수집 불가 |
| 이용절차·일반문의 문장 만들기 | `support-first/service/` | 수집 불가, 외부 카카오 채널로 사용자가 직접 이동 |
| 실제 일반 문의 | 기존 울모아 카카오채널 | 채널의 운영 규정과 개인정보처리 방침에 따라 **최소정보**만. 임상기록 전송 금지 |
| 내부 업무 흐름(접수코드만) | 별도 비공개 Google Sheets 6개 탭 | 학생 실명·학교·전화번호·진단·상담 원문 금지 |
| 전문 임상 기록 | 추후 별도 적법한 접근통제 시스템 | 아직 **연결·운영 미완료** |

> 절대로 공개 GitHub 이슈, GitHub Pages, 일반 댓글, 운영표에 학생의 실명·연락처·상담 원문을 적지 않는다.

## 2. 최소 운영절차

**도움 찾기** → **일반 문의(선택적)** → **운영시간 내 사람이 확인** → **안전·업무범위·연령 동의 확인** → **지원방식 결정** → **실행 및 평가** → **종결·연계확인**.

### 문의가 들어왔을 때
1. 직원이 정해진 운영시간에 카카오채널·전화 등 공식 채널을 점검한다. **운영시간과 답변 가능 기한은 개설 전에 실제 인력일정으로 확정**한다. 실시간/24시간 응대 약속 금지.
2. 즉각적 위험·학대·성착취·자해·타해 등 위기정보가 보이면 메시지 분류나 자동화보다 **현지 긴급기관 112/119, 1388 및 적격 전문기관 연결**을 우선한다. 상황에 맞는 법적 보호·신고 의무 검토. 위기관련 상담세부 내용은 일반 운영표에 쓰지 않는다.
3. 일반 문의는 가명 코드 `YS-연도-순번`을 부여한다. Sheet에는 접수일·경로·대범주·상태·역할·다음 확인일만 기록한다. 매핑표를 같은 Sheet/폴더에 저장하지 않는다.
4. 단계별 설명을 제공한 후 적격 서비스 범위 확인. 학생의 선택·발달·언어수준·동의 여부 확인. 필요한 경우 전문기관에 의뢰한다.
5. 개인별 수업 전 보호자 동의 및 학생의 자발적 참여를 별도로 확인하고, 비용·취소·제공시간·장소·녹화 금지/허용 등 서면 조건을 정한다.
6. 4~8회기 간 목표행동·기초선·실생활 전이를 기록하고, 필요한 경우 재설정·종결. AI 사용 여부는 학생 적합성을 기준으로 결정한다.

## 3. 상태 정의(운영표 선택지)

- 신규: 일반 문의 확인 필요
- 검토 중: 초기 정보/지원범위 검토
- 확인 대기: 본인·보호자 동의 및 세부 이용조건 확인 전
- 수업 중: 동의·계약 후 실제 수업 제공
- 연계 중: 적격기관 안내 이후 확인 대기
- 연계 완료: 안내·연계 결과 확인 가능
- 보류: 학생 동의 없음, 일정/자원 제약, 서비스 부적합, 다른 기관 우선
- 종료: 학생/보호자의 중단 의사·목표 종료 또는 타 기관으로 인계

**상태 변경 시** 일자·변경 상태·정형 조치 코드·다음 확인일을 상태이력에 남긴다. 민감 사례를 정형 상태 코드로 대체하지 말고, 법에 맞는 별도 전문 기록체계 확보 전에는 해당 정보를 수집·보관하지 않는다.

## 4. 담당자 역할과 업무량

- 접수 담당: 일반 문의 채널 점검·코드 발급·다음 확인 일정
- 안전/적합성 담당: 역할 범위 및 긴급 전문기관 연결 결정. 위기 평가 전문자격 대체 금지
- 수업 담당: 동의 확인, 목표·활동·실생활 전이 평가
- 운영 관리자: 무료지원 잔여 한도·처리 지연·개인정보 최소화·공개 문구 월 1회 감사

하나의 직원이 여러 역할을 맡을 수 있으나 **업무 분장과 실제 근무시간은 운영 개시 전 문서로 확정**한다.

## 5. 무료지원 운영 원칙

- 무료 **공개자료·도움 찾기**는 누구나 사용. 무료 **1:1 수업**은 별도 심사·수용 인원 기준.
- 선정 기준은 필요도·기존 지원 접근 제약·경제적/지역적 장벽·학생 참여 의사·서비스 적합성 및 남은 인력시간을 종합. 진단명이나 홍보가치를 기준으로 선발하지 않음.
- 무료 수업을 조건으로 후기·팔로우·SNS 인증·공개사례 제공을 요구하지 않음.
- 무료지원도 제공기간, 횟수, 종료/연계 기준과 대체 공공기관 안내를 문서로 고지.

## 6. 초기 선별 및 연계 원칙

| 구분 | 예시 | 기본 대응 |
|---|---|---|
| 일반정보 | 검정고시, 금융안전, 자료 찾기 | 공개자료·공식기관 안내 |
| 인지·의사소통 지원 | 자기표현, 또래 대화, 실행기능 | 교육적/인지 기능 평가 후 개별수업 적합성 검토 |
| 협업 우선 | 등교 곤란 장기화, 학교폭력, 뚜렷한 우울·불안 의심 | 관련 적격 전문기관·학교·보호자 지원체계 협력 |
| 즉각적 위험 | 신체 위험·자해·타해·학대·성착취 등 | 공공 긴급·위기전문 기관 안내·연계, 상황별 법적 의무 준수 |

위 구분은 **전문 위기 평가도구도 진단도 아니다.** 학생 자신이 말을 하지 않는다는 이유로 위험이 없다고 판단할 수 없다.

## 7. 개인정보 및 청소년 동의

- 공개 페이지에 접수 폼, 녹음, AI 상담 챗봇, 외부 자동전송을 넣지 않음.
- 청소년이 첫 메시지에 실명·주소·학교·진단·건강정보를 보내지 않도록 안내. 실제 계약 단계에서는 개인정보 처리방침·필요항목·보유기간·위탁/국외이전·열람/삭제 방법 등 확정.
- 만 14세 미만 개인정보 수집·이용의 동의는 법정대리인 확인 요건 준수. 개별 미성년자 서비스 계약 및 긴급 보호의무는 별도 검토.
- 학생이 원하지 않는 대면·눈맞춤·마이크/카메라 사용을 강요하지 않음.
- 계정·로그인·비공개 저장소, 역할별 접근권한, 직원 비밀유지, 분실·침해 대응절차가 준비되기 전까지 실제 상담기록 데이터베이스 **개설 금지**.

## 8. 주간·월간 점검

**주 1회**: 신규/검토/확인대기 누락 여부, 다음 확인일 도과, 연계 중 건의 진행 여부, 학생의 거절·중단 의사 존중 확인.  
**월 1회**: 무료지원 신청·선정의 공정성, 지원 지속·종결, 유료 수업 전환 압박 유무, 도움찾기 화면 사용성, 외부 링크와 법적 안내, 직원 업무량 평가.

학생 수업 효과는 AI 사용량이 아니라 사람과의 실제 의사소통·행동·생활 참여 및 부담 정도를 기초선과 비교한다.

- [ ] 보호자 동의·학생 참여 의사, 비밀보장 한계·위기 신고·기관 연계 절차
- [ ] 상담·치료 범위와 자격/교육사업 관련 규정·해외 제공 국가별 규정 검토
