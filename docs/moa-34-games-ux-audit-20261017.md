# 일단 해봄 · 다섯 정원 34개 게임 기능·화면 전수 검토
검토: 2026-10-17 · 기준 코드: GitHub 저장소의 26개 인지·생각·학습 링크 및 별도 음악·호흡·미션 프로그램.

## 검토 원칙
- 이 문서는 **코드·게임 조작 방식·정원 목록·실제 화면 캡처 기반의 기술/UX 검토**다. 아동 참여 검증이나 임상 효과 입증을 의미하지 않는다.
- 구별해야 할 핵심: **무엇을 누르는지**(조작), **어떤 정보를 처리하는지**(활동 목표), **실생활에서 유사한 장면**(연결 예시). 단일 게임 성적을 인지·정서 능력 점수처럼 해석하지 않는다.
- 캐릭터 색에는 집중·기억·난이도 등 **기능 의미를 억지로 부여하지 않는다**. 분류는 텍스트+아이콘으로 표시한다.
- 공통 개선: 활동 목표, 실제 행동 3단계, 모바일 글자 대비·키보드 포커스, 기존 게임 링크 유지, 미리보기 캡처.
- 주요 개별 개선: `hide`의 무작위 탐색 → 흔적 찾기, `path`의 순서 기억 오분류 해소, `sameShape` 목표 구역 강화, `flower` 수집 바구니, `targets` 꽃씨 성장, `paint` 모바일 드래그 처리.
- 별도 게임은 기존 카메라·마이크·판정 시스템을 보존하고 **도움말만 독립 삽입**. 내부 정확도나 임상 적합성이 자동으로 개선되었다는 뜻은 아니다.

## 공개 전 자동 검사
- 34개 전체: 게임 시작 경로, 페이지 렌더링, 목표 안내 노출, 3단계 안내, 모바일 가로 넘침, JS 예외 검사.
- 공통 엔진 24개: 모바일·데스크톱 실제 시작 후 첫 스테이지 확인.
- 별도 10개: 게임별 개별 화면에서 안내, 버튼 및 페이지 초기화 검사.
- 정원 라이브러리: 34개 연결, 실제 캡처, 전체 검색·필터·미리보기 회귀 검사.
- **아직 확인되지 않은 것:** 실제 아동의 난이도 적합성·재미·수업 적용·원격 카메라/마이크 장치별 정확도. 실제 치료효과가 입증된 프로그램이라는 표현 금지.

## 후속 개발 우선순위
1. 사용자 위험·임상적 타당성: 마이크 감도/호흡 안전, 실기기 카메라 손동작, 감정 단답식 오해, 시각/청각 중복 단서 정확성.
2. 조작 오류: 모바일 그리기, 보이지 않는 터치 영역, 힌트 불명확, 단계별 판정 시각화.
3. 스토리와 동기: 정원별 다른 임무, 게임의 고유한 보상, 휴식·재시도 선택.
4. 중복 방지: 동일한 기초 과제 여러 게임은 테마만 바꿔 늘리지 않고 단계·문제 은행을 강화.

이 문서는 **완료/미완료를 구분하는 유지보수용 기록**이다. 모든 게임을 완전히 재개발했다는 보고가 아니다.
