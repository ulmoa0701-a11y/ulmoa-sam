01

작업기억

필요한 정보를 잠깐 유지하면서 다루기

핵심 보기 +접기 ↑
딱 이것만 기억
유지하기+다루기

과제에 필요한 정보를 잠깐 머릿속에 유지하면서, 동시에 사용하거나 업데이트하는 능력.

예시

공책 펴기 → 날짜 쓰기 → 3번 풀기
순서를 기억한 채 하나씩 실행하기.

× 잠깐 외우기만○ 유지하면서 처리하기
여러 단계 지시암산문장 연결받아쓰기
더 알아보기 · 근거

헷갈림 단기기억은 잠깐 유지하는 데 초점을 두는 표현이고, 작업기억은 유지한 정보를 과제에 맞게 다루는 과정까지 포함해 설명하는 경우가 많아요.

실수 한 번으로 작업기억이 낮다고 판단할 수는 없어요. 주의, 언어이해, 과제 복잡성도 영향을 줍니다.

참고NIMH · Working Memory ↗Baddeley, 1992 · PubMed ↗
02

처리속도

정보를 처리하고 반응하는 데 걸리는 시간

핵심 보기 +접기 ↑
정식 의미에 가깝게
정보 처리+반응 시간

처리속도는 정보를 처리하고 질문이나 과제에 반응하는 데 걸리는 시간을 가리켜요.

예시

NIH Toolbox의 한 처리속도 과제처럼, 두 그림이 같은지 다른지 판단해 제한된 시간 안에 정확하게 반응하기.

× 느리면 이해력이 낮다○ 처리속도와 이해력 전체는 같은 뜻이 아니다
처리 시간반응정확도시간제한 과제
더 알아보기 · 근거

메모 처리속도는 하나의 과제로 완전히 분리해 재는 능력이 아니에요. 어떤 검사를 쓰느냐에 따라 시각탐색, 선택반응, 손으로 표시하는 방식 같은 요구가 함께 들어갈 수 있습니다.

따라서 처리속도 점수 하나만으로 ‘생각이 느리다’, ‘이해가 느리다’고 단정하면 안 됩니다.

참고NCBI Bookshelf · Processing Speed ↗NIH Toolbox · Pattern Comparison ↗
03

기억

부호화 → 저장·공고화 → 인출

핵심 보기 +접기 ↑
선언기억의 기본 과정
부호화정보를 받아들이기→저장·공고화기억을 안정화하기→인출필요할 때 떠올리기

사실이나 사건에 대한 기억은 부호화하고, 저장·공고화하고, 필요할 때 인출하는 과정으로 설명할 수 있어요.

예시

새 단어를 배우고 → 며칠 뒤 질문에서 다시 떠올리기.

× 기억 못함 = 저장 문제○ 부호화·저장·인출을 나눠 보기
부호화저장인출
더 알아보기 · 근거

헷갈림 겉으로는 모두 “기억을 못 했어요”처럼 보여도 부호화가 충분하지 않았는지, 저장·공고화가 어려웠는지, 인출이 잘 되지 않았는지는 다를 수 있어요.

기억 전체가 언제나 세 단계로 순서대로만 작동한다는 뜻은 아니에요. 여기서는 선언기억을 이해할 때 구분하는 핵심 과정을 정리했습니다.

참고NIMH · Declarative Memory ↗
04

시각주의와 시지각

주의는 선택·배분 / 지각은 시각정보의 구성·해석

핵심 보기 +접기 ↑
NIMH 기준으로 구분
시각주의무엇을 우선 볼까?제한된 주의 자원을 필요한 시각정보에 선택적으로 배분
시지각본 정보를 어떻게 이해할까?시각정보를 바탕으로 형태·위치·관계를 구성하고 해석
예시

여러 기호 중 별을 찾아 주의를 두는 것에는 주의가 중요하고, 찾은 도형의 모양·방향·위치 관계를 구별하는 것에는 지각 과정이 함께 필요해요.

× 별 찾기 = 시각주의만○ 실제 과제에서는 주의와 지각이 함께 작동
더 알아보기 · 근거

메모 NIMH는 주의를 제한된 처리 체계에 무엇이 접근할지를 조절하는 과정으로, 지각을 감각정보를 바탕으로 외부환경의 표상을 구성·변환하는 과정으로 구분합니다.

그래서 한 과제에서 틀렸다는 사실만으로 ‘시각주의 문제’ 또는 ‘시지각 문제’라고 바로 단정하기 어렵습니다.

참고NIMH · Attention ↗NIMH · Perception ↗
05

청력과 청각처리

소리 감지와 중추 청각정보 처리는 같은 개념이 아님

핵심 보기 +접기 ↑
ASHA 기준으로 구분
소리 감지≠중추 청각처리

소리가 귀에 들어오는 것과, 들어온 청각정보를 중추청각신경계에서 분석·조직·처리하는 것은 구분해서 봐야 해요.

소리 구별시간적 처리양이청 처리소음·왜곡된 소리 속 듣기
예시

ASHA가 제시하는 청각처리 영역에는 비슷한 소리 구별, 시간 정보 처리, 경쟁하는 소리 속에서 듣기 등이 포함돼요.

× 듣기 어려움 = 바로 CAPD○ 청력·언어·주의·학습과 감별 필요
더 알아보기 · 근거

중요 ASHA는 CAPD를 중추청각신경계에서의 청각정보 신경처리 문제로 정의하며, 고차 언어·인지 요인 때문인 경우와 구분해야 한다고 설명합니다.

그래서 ‘말을 잘 못 알아듣는다’, ‘시끄러운 곳에서 어렵다’는 관찰만으로 CAPD라고 판단할 수 없습니다. 청각학적 평가와 감별이 필요합니다.

참고ASHA · Central Auditory Processing ↗
