# 일단써봄 v15 — 임상적 사용 가이드와 배포 안전 점검

> **상태: 가상 데이터 체험판. 실제 아동·보호자·치료사의 건강·상담 정보를 입력하지 마세요.**  
> 화면의 가상 역할 전환, 모의 API, 브라우저 자동 테스트는 안전한 실사용 인증·저장·권한 검증의 증거가 아닙니다.
> 이 도구는 진단·치료·위기개입의 대체제가 아닙니다.

## 1. 목적과 사용 원칙

- **학생에게 기록은 선택 사항**입니다. 매일 입력, 최소 횟수·글자 수, 증상 빈도/강도 체크, 출석형 보상, 연속 기록 알림이 없습니다.
- 학생이 쓰고 싶은 **경험·일상·생각**을 자기 언어로 남기며, 상세 감정/신체감각/반복경험 항목은 모두 선택입니다.
- 학생은 공유할 내용을 직접 선택합니다. 기록하지 않음은 치료 실패나 순응도 저하로 해석하지 않습니다.
- 치료사는 공유 기록을 실무 참고자료로만 사용하고 **기록을 안 했다는 이유로 재촉하거나 질책하지 않습니다**.
- 학생 기록 ≠ 객관적 사실. 보호자 관찰 ≠ 학생 의도. 치료사 가설 ≠ 진단. 각 출처와 확실성은 구별합니다.
- 위기 상황이나 긴급한 지원을 앱 기록으로 요청하지 않습니다. 별도의 연락·대응 절차가 필요합니다.

## 2. 기법에 대한 정확한 표현

| 기능 | 참고한 접근 | 주장하면 안 되는 것 |
|---|---|---|
| 간편/자세히 기록 | 자유 일기 및 선택적 자기관찰 | 앱 사용만으로 CBT 치료 효과가 확인되었다 |
| 감정·몸·경험 | CBT의 자기관찰 개념 일부 | 표준화된 CBT 사고기록지 또는 치료 프로토콜이다 |
| 보호자 사건 전후 관찰 | ABC 행동관찰, 환경·가족 맥락 | 하나의 ABC 사례로 행동의 원인을 확정한다 |
| 치료사 가설·대안·영향 | 사례개념화와 임상 면담 보조 | 앱이 감별진단을 수행한다 |
| ERP·CBIT 검토란 | 근거 기반 치료의 평가·계획 개념 | ERP/CBIT 치료 자체가 앱에서 제공된다 |

근거에 기초한 **프로그램 설계**와 **이 프로그램의 임상적 효과 검증**은 구별해야 합니다. 후자는 아직 시행되지 않았습니다.

## 3. 치료사 전용 메모 사용법

기본 메모는 학생 직접 진술 / 보호자가 전한 내용 / 치료사가 직접 관찰한 사실 / 다음 회기에서 합의한 계획을 분리합니다.

필요할 때만 다음 항목을 펼칩니다.

- **사례개념화**: 실제 생활 영향, 가족·주변의 반응, 잠정 가설, 다른 가능한 설명, 확인이 부족한 점
- **기록 부담 확인**: 기록의 압박감, 반복 수정·확인, 기록하느라 일상이 지연되는지 등
- **CBT·ERP 검토**: 필요성/적합성, 별도의 평가·협력적 개입 계획, 안전·경과를 *치료사 내부*에 기록
- **CBIT 검토**: 틱 관련 평가와 생활 영향, 실제 훈련계획이 있을 때만 그 내용 기록

**체크박스 하나나 특정 표현 때문에 ERP/CBIT를 자동으로 적용해서는 안 됩니다.** 노출·반응방지, 경쟁반응 등은 해당 기법 역량을 갖춘 전문가가 평가하고 합의한 계획 아래 시행합니다. 틱과 강박적 행동은 혼동하지 않습니다.

## 4. 위험 신호 — 기록 방식 재평가 또는 일시 중단

다음이 확인되면 앱 사용을 **축소·일시 중단하거나 다른 방식(면담·구두 기록 등)으로 대체**할지 학생과 함께 결정합니다.

1. 기록을 완벽하게 써야 한다고 느껴 작성·삭제·재작성 시간이 길어짐
2. 작성한 내용을 계속 다시 확인하거나 확신을 얻기 위해 보여 줌
3. 특정 감각·움직임·반복 행동을 지속적으로 감시하게 됨
4. 불안·짜증·수치심·수면 문제 또는 일상 기능 저하가 기록 활동과 함께 악화됨
5. 보호자가 학생에게 기록을 요구하거나 앱 내용을 이용해 비난·통제함
6. 학생이 비밀로 두길 원한 기록을 의도치 않게 다른 역할에서 확인함

위 사항은 자동 진단 규칙이 아니라 **전문가가 면담에서 확인해야 할 사용 중단/조정 신호**입니다. 악화가 앱 때문인지 단정하지 않고 맥락을 함께 검토합니다.

## 5. 4회기 시범 적합성 확인(치료 효과 평가 아님)

| 회기 | 확인할 것 |
|---|---|
| 1 | 가상 데이터로 사용법·선택권·비공개·공유 범위 설명, 학생의 이해 확인 |
| 2 | 학생이 원할 때 자유 기록을 선택했는지, 쓰지 않아도 부담이 없었는지 |
| 3 | 실제 상담에 도움이 된 정보와 반복 확인·안심 요구 등 부작용 신호 확인 |
| 4 | 학생·보호자·치료사의 부담과 이익을 종합해 유지·축소·중단 결정 |

기록 횟수/글자 수/일일 접속률을 치료 성과 지표로 삼지 않습니다. 짧은 시범으로 치료 효과를 주장하지 않습니다.

## 6. 실제 개인정보 수집 전 필수 운영 조건

- 실제 학생/보호자/치료사 계정 인증, 학생·보호자·치료사·관리자 간 서버 기반 권한분리 및 침해 시험
- 저장·전송 암호화, 키 관리, 수정·삭제·공유 철회 및 복사본/백업에 대한 명확한 한계 설명
- 계정 및 기기 분실·복구, 접근 기록·감사, 사고 대응, 보존기간과 파기 절차
- 아동 및 법정대리인 동의, 적법한 민감정보 처리, 위탁 서비스 및 국외 이전 여부 확인
- 실제 HTTPS+DB+Google OAuth·Drive를 포함한 통합 QA, 별도 위협 모델 및 보안 검토
- 치료사별 승인 범위, 실사용 전 접근성·이해도·사용부담 평가

**현재 v15 체험판에는 이 조건들이 충족되지 않았으므로 실제 상담정보 입력 금지.**
