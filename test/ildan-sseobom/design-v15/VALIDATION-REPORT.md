## 3. 운영 전 차단 사항 — P0

### 3-1. UI와 실제 보안 서버는 동일한 서비스가 아님

공개 `design-v15/`는 `window.ILDAN_PREVIEW=true`이고 `window.fetch`를 가상 API로 바꿉니다. 가상 계정의 역할은 브라우저에서 바뀔 수 있고, 데이터가 자바스크립트 전역 변수에 있으므로 **실제 서버 인증·비밀보장·민감정보 보호를 시험한 것이 아닙니다**.

Netlify에는 `ulmoa-ildan-secure-test` 프로젝트 항목이 존재하나, 별도 비로그인 URL 확인 시 루트와 `/api/health`에서 모두 404를 받았습니다. SSO 등 방문 제약·배포설정의 영향도 가능하므로 "서버가 안전하게 운영 중"이나 "미구현"으로 단정할 수 없습니다. 실제 HTTPS 계정·DB·OAuth 통합 기능은 **검증 미완료**입니다.

### 3-2. 백엔드-프런트엔드 불일치

확인한 개발 브랜치 `secure-portal/netlify/functions/api.mjs`에는 다음 문제가 있습니다.

1. `ENTRY_KEYS`에 v15 보호자 `childWords`가 없음. 이 필드는 서버의 `validateEntry`에서 제외되어 **보존되지 않을 수 있음**.
2. v15 보호자 `origin`에 있는 '그 밖의 사람에게 들음' 값은 백엔드 `validateEntry` 허용값에서 제외돼 요청이 **거절될 수 있음**.
3. 회기 메모 서버 입력 화이트리스트가 `observation`, `question`, `plan`만 허용. 학생/보호자 진술·기능 영향·가설·대안·부담 검토·ERP/CBIT 메모는 **저장되지 않음**.
4. 서버에 `path==='unshare'`가 확인되지 않음. 공개 체험판의 공유 철회 기능을 실제 API에서 호출하면 **동작한다고 보장할 수 없음**.
5. 공유 기록의 Google Drive 동기화 코드는 존재하나, 공유 취소 시 이미 복사된 파일의 사용·삭제·보유 방침 및 기술적 동작은 **검증되지 않음**.

**실운영 전 위 API 계약을 통일하고 실제 인증 계정별 통합·권한·삭제·백업 시험을 수행해야 합니다.**

### 3-3. 개인정보·법적 운영

민감한 건강 및 상담정보의 동의·법정대리인 관계, 제공 범위, 보존기간, 삭제/철회, 재등록, 분실·침해 대응, 로그·백업 및 제3자 위탁/국외 이전 여부에 대해 개인정보보호 전문가 점검이 필요합니다. 연령에 따라 필요한 동의·설명과 접근권한 정책이 달라질 수 있습니다. 현 체험판은 실제 정보 입력 금지.

## 4. 임상적 근거의 확인과 한계

| 근거 자료 | 확인한 결론 | 이 프로그램에서 주장 가능한 범위 |
|---|---|---|
| NICE CG31 (OCD/BDD) | 아동·청소년의 발달 수준에 맞춘 가족 참여 CBT/ERP, 협력적 목표 설정, 훈련된 치료사 필요 | 학생의 선택권과 치료사 주도 평가에 대한 설계 참고. 일기 자체가 치료 아님 |
| Andrén 등, ESSTS 틱장애 행동중재 지침 (2022) | HRT/CBIT가 근거 기반 중재 | 경험 기록은 CBIT와 동일하지 않음. 자동 경쟁반응 처방 금지 |
| Lebowitz 등, 아동 OCD 가족 수용행동 연구·검토 (2012) | 가족의 실제 반응과 수용행동을 평가하는 중요성 | 보호자 반응/상황의 자료 수집을 고려할 근거. 메모만으로 가족 수용행동 진단 불가 |
| 미 교육부 FBA (2024) | 선행·행동·후속 사건과 관련 맥락의 다각적 자료 수집 필요 | ABC 형식은 전문가의 가설 수립에 참고. FBA 완료나 인과관계 증명 아님 |
| Henry 등, 청소년 EMA 메타분석 (2026; 130연구, 14,400명) | 반복적인 기록 연구에서 참여 부담·중도 이탈·순응률 차이 존재 | 의무 기록·알림을 신중히 다룰 이유. **EMA 연구는 자발적 자유일기의 효과 검증 아님** |

### 특정 학생에게 적용할 때 위험요인

- ADHD: 기록의 미루기/완벽주의·과제 전환 어려움을 고려하되, "ADHD에는 이 양식이 효과적"으로 단정하지 않음
- 틱: 증상에 대한 과도한 주의·억제·기록 강요 여부를 확인, 기록은 선택
- 강박·반복 확인: 글의 맞춤법/내용을 반복 수정하거나 확신을 얻으려는 행동이 증가하면 기록 축소/중단 고려
- 인공와우/청각적 접근성: 음성 알림만으로 중요한 내용을 전달하지 않고 문자 중심 안내 유지
- 보호자: 행동 원인에 대한 추측이나 의도적 상시 모니터링을 피하고, 실제 관찰과 전해 들은 내용을 구분
- 치료사: 학생 기록·보호자 보고·직접 관찰·잠정 가설·다른 설명을 구분, 단일 기록으로 감별진단/치료 효과 판단 금지

위 6개 평가는 **합성 사례에 대한 설계 위험 검토**이지 실제 참여자 관찰, 전문가 합의 연구나 임상시험이 아닙니다.
