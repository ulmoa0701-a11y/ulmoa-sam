# 일단써봄 치료사·학생·보호자 휴대전화 로그인 (SMS 미사용)

2026-10-15: 문자 인증번호 수신을 원치 않는 운영 방식으로 변경.

- 첫 화면에서 학생·보호자·치료사 **모두 동일한** `휴대전화 기기 인증으로 로그인` 버튼 사용.
- Supabase `signInWithPasskey()`를 사용하여 지문·얼굴·기기 PIN 같은 운영체제 인증을 이용. 휴대전화번호 자체로 사람의 신원이 검증되지는 않습니다.
- `signInWithOtp({phone})`, `verifyOtp({phone,type:'sms'})`, `signInWithOtp({email})` 호출을 삭제. SMS·이메일 인증번호 요청 양식 제거. 브라우저에 SMS 제공업체/비용 관련 문구도 없음.
- 학생·보호자는 기존 **역할별 48시간 단회 링크** 경로를 유지. 링크 미리보기는 초대를 소진하지 않고 카카오톡/브라우저 전환 시 원본 링크를 복사하여 이어갈 수 있음.
- 치료사 **최초 등록**은 운영자 신원 확인/승인 후 계정과 패스키 연결 필요. 전화번호를 로그인 비밀번호로 사용하거나, 전화번호만 아는 사람이 치료사 계정을 생성하도록 허용하지 않음.
- 개인정보 포함 임상 기록 저장은 `CLINICAL_WRITES_ENABLED=true` 검증 전까지 중지. 신규 계정 등록은 `INVITE_REGISTRATION_ENABLED=true` 검증 전까지 중지.
- Supabase Dashboard의 실험적 Passkeys가 비활성이라면 기기 인증 로그인은 실패함. 기기별 브라우저 호환성·계정 복구·실제 사용자 승인 테스트가 필요함.
- **현재 검증본은 디자인 및 권한 구조 확인용**이며 문자 수신이나 전화번호 입력을 요구하지 않음. 실제 최초 등록과 상담기록 실사용까지 완료된 것은 아님.

보안 원칙: 전화번호는 계정 식별용 메타데이터가 될 수 있으나 SMS를 쓰지 않는 한 번호 소유를 검증한 것이 아니다. 실제 인증은 패스키의 서명 및 Supabase 세션으로 처리하고, 치료사 권한은 신뢰된 운영자만 부여해야 함.
