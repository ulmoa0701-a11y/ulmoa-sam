# 일단 해봄노트

인지·발달·특수교육 현장에서 필요해서 만든 자료와 도구를 직접 써보고 나누는 사이트입니다.

공개 사이트: https://ulmoa0701-a11y.github.io/ulmoa-sam/

## 현재 구조
- `index.html` — 홈 / 바로 써보기
- `materials/` — 실제 PDF·PNG 자료 책장
- `thinking-garden/` — 모아의 생각정원
- `heart-score/` — 하트색깔악보 Studio
- `info/` — 정보
- `about/` — 소개
- `request/` — 필요한 자료 제안
- `CONTENT-ROADMAP.md` — 콘텐츠 편입·확장 기준

## 운영 원칙
- 완성되어 실제로 사용할 수 있는 것만 공개한다.
- 자료 표지는 실제 PDF 첫 페이지 또는 실제 대표 이미지를 사용한다.
- 사이트는 다운로드·도구 사용의 원본 위치로 두고 블로그/SNS는 유입 채널로 활용한다.
- 외부 제작자 참여는 자료실 아래의 `나도 만들어봤어요` 제안 창구로만 받는다.
- BAND·오픈채팅·마켓·제작자 플랫폼은 실제 수요가 생길 때까지 보류한다.
- 검색엔진 공개 페이지는 `index,follow`; 비공개가 필요한 페이지는 별도로 관리한다.

## 다음 우선순위
새 페이지를 늘리기보다 기존 제작물을 전수조사해 자료실에 편입하고, 생각정원과 하트색깔악보의 실제 사용성을 높인다.
