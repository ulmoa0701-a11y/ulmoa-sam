# 울모아쌤 브랜드 사이트 1차 프리뷰

정적 HTML/CSS/JS로 만든 GitHub Pages 배포용 구조입니다.

## 권장 운영
- 소스: GitHub 공개 저장소
- 호스팅: GitHub Pages
- 초기 URL: https://ulmoa0701-a11y.github.io/ulmoa-sam/
- 추후: 검수 후 ssam.ulmoa.co.kr 같은 서브도메인 연결 검토

## 구조
- index.html: 홈 / 검색 / 도구 카드 / 아이디어 창고 / 피드백
- about/index.html: 개인 소개
- assets/styles.css: 비주얼 시스템
- assets/app.js: 검색·필터·프리뷰 인터랙션

## 공개 전 교체할 것
- noindex,nofollow 제거
- 실제 공개 가능한 대표도구 URL 연결
- 후원 수단은 세무·표기 검토 후 연결
- 개인정보 안내/이용 안내 페이지 추가
- OG 이미지 및 favicon 추가
