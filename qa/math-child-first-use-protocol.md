# 모아의 숫자 숲 — 가정·아동 최초 사용성 및 초기수학 반응 관찰지 (내부 QA 초안)

> 본 문서는 **아동의 실제 수학 학습효과 검증 보고서가 아니라**, 도움 없이 게임을 시작하고 수학적 행동을 이해하는지 관찰하기 위한 현장용 체크리스트다. 자동 Playwright 통과와 실제 아동 몰입·개념 학습은 서로 다른 결과다.

## 적용 범위 및 안전
- 최초 사용자 5~8명 정도를 여러 발달·읽기·조작 수준에서 관찰하는 **탐색적 사용성 점검**이다. 적은 수의 편의표집 결과를 일반화하거나 치료효과로 홍보하지 않는다.
- 보호자에게 목적(화면 이해·조작 확인)과 중단 가능성을 설명하고 동의받는다. 아동이 원치 않으면 즉시 중단한다.
- 아동 실명·생년월일·진단명·얼굴 영상·음성 파일 등을 GitHub/공개 Drive/공개 QA 파일에 기록하거나 업로드하지 않는다. 사례 메모는 별도 보호된 환경에서 관리한다.
- 게임은 무료이며 앱 설치, 계정, 유료 API가 필요 없어야 한다. 기록은 기기 안에만 남으므로 가족 공용 기기에서 여러 아동의 기록이 섞일 수 있다. 평가 목적으로는 새 개인 브라우저 프로필 또는 시크릿 창을 쓴다.
- 피드백은 동작 수행 관찰 자료일 뿐 표준화 검사·진단 점수 또는 '수학 향상' 판정이 아니다.

## 사용성 관찰 (한 아동당 약 5~10분; 성인 개입은 가능한 한 최소화)

| 항목 | 관찰 장면 | 기록 기준 |
|---|---|---|
| ① 놀이 입장 | 도토리 배달 대작전 처음 열기 | 시작 버튼을 스스로 찾음 / 한 번 안내 / 찾지 못함 |
| ② 사물 인지 | 나무·바구니·도토리·접시 | 설명 없이 구별함 / 혼동 있음(어떤 사물인지) |
| ③ 행동 발견 | 첫 간식 담기 | 스스로 시작 / 그림 시범 후 / 직접 도움 필요 |
| ④ 조작의 독립성 | 도토리 선택 및 바구니 되돌리기 | 의도한 선택 / 비의도적 탭·누락 / 조작 불가능 |
| ⑤ 수량 계획 | 2~4명에게 필요한 양 준비 | 처음부터 적절 / 모자람·남음 뒤 수정 / 시범 필요 |
| ⑥ 오류 후 회복 | 간식 부족·남음 장면 | 결과 이해 후 수정 / 같은 오류 반복 / 중단 |
| ⑦ 숫자 외적 판단 | 색·위치가 달라도 같은 수량인가 | 새 장면에서 독립 해결 / 도움 후 해결 / 미확인 |
| ⑧ 지속 참여 | 5분 이내 | 이어서 하려 함 / 지루해함 / 중단·피로 / 불안 |
| ⑨ 기기·화면 | 모바일·태블릿·PC 중 사용 기기 | 화면 겹침·잘림 / 터치 영역 협소 / 문제 없음 |
| ⑩ 종료·복귀 | 다른 놀이/나가기 선택 | 스스로 이동 / 안내 필요 / 길을 잃음 |

**특히 구분:** 도토리 3개를 모두 눌러 완료한 것과, 친구 3명에게 줄 도토리 3개를 먼저 골라 준비한 것은 서로 다른 행동이다. 힌트 후 정답과 최초 독립 정답을 합쳐 세지 않는다.

## 사전·사후 점검의 차이

- **사용성:** 처음 보는 아동이 화면을 이해하고, 실수 없이 터치하고, 다시 시도할 수 있는지.
- **게임 내 수행:** 첫 독립 수행 / 오답 후 수정 / 시범·힌트 후 수행을 별도 집계.
- **유지:** 다음 날 또는 1주 후 비슷한 개념을 새로운 배열에서 다시 풀어 보는지.
- **실생활 적용:** 바구니 그림이 아닌 실제 간식·물건 나누기 같은 맥락에서 유사 관계가 나타나는지.
- **효과 연구:** 위 관찰만으로는 인과적 효과를 증명할 수 없다. 유효한 비교설계와 타당한 측정이 필요하다.

## 개발 반영 우선순위 (심각도 기준)

- **P0 기능 문제:** 아이가 선택해도 다른 수량이 표시되거나 정답이 자동 누출됨, 진도 오기록, 모바일에서 게임 진행 불가.
- **P1 이해 문제:** 나무/바구니가 즉시 식별되지 않음, 시작 행동을 이해하지 못함, 도움 없는 풀이를 과대평가.
- **P2 게임성 문제:** 화면은 이해하지만 매회 같은 클릭만 반복하여 목표 없이 지루해함.
- **P3 장식 문제:** 수학 판단·접근성에 영향 없는 미세한 시각 요소.

임의로 정한 '성공률 80%' 같은 수치는 임상적 규준으로 사용하지 않는다. 현장 사용 후 지표를 근거로 변경할 수 있다.
