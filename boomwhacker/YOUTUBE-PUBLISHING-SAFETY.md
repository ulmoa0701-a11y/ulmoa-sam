# 붐웨커 Studio — 유튜브 공개 전 권리·표현 검토 (2026-10-17)

> 운영 목적: YBM을 포함한 제3자 붐웨커 영상의 **일반적인 연주 원리**를 사용하더라도, 특정 작품의 **창작적 표현**을 복제하거나 무허가 음악을 싣지 않는다.
>
> **'유튜브 공개용' 버튼은 저작권 면책 또는 권리 검증 서비스가 아니다.** 기술적으로 확실히 구분 가능한 고위험 입력만 차단하고, 창작곡의 독창성·음악 권리·화면의 실질적 유사성은 사람이 검토한다.

## 무엇을 반박·수정했는가

| 기존의 과도한 낙관 | 실제 위험 | 제품 대응 |
| --- | --- | --- |
| 내 코드면 저작권 침해가 아니다 | 코드가 달라도 화면·애니메이션의 실질적 유사성이 쟁점이 될 수 있음 | YBM 그래픽·브랜드·영상·음원을 재사용하지 않음. 공개용 인트로에서 제3자 브랜드로 읽힐 요소를 줄이고 자체 브랜드 표시 |
| 창작곡이면 바로 게시 | 무의식적 모방, 차용, 이용 허락받지 않은 가사, 편곡은 코드만으로 판별할 수 없음 | 내장 자체 연습곡 8개만 공개용 선택 허용. 게시자가 별도 수동 확인 |
| 음악 출처만 쓰면 해결 | 적법한 이용 근거 없이 출처만 쓰는 것은 사용 허락이 아님 | 외부 MR 차단, 피아노 샘플 CC BY 4.0 표시와 설명문 출처 제공 |
| 교육용·비영리라 안전 | 유튜브에 공개 업로드하는 행위는 수업실 사용과 다름 | 수업용 영상 저장과 공개 검토용 영상 저장 분리 |
| 업로드 검사 통과=무조건 합법 | 자동 Content ID 감지는 누락되거나 부정확할 수 있고 수동 삭제 요청 가능 | 업로드 전/후 제한·권리 주장 확인, 기록 보관 |
| 영상 ©만 표시하면 충분 | 외부 CC BY 음원까지 독점 저작권으로 오해시킬 수 있음 | '자체 제작 화면·편집'으로 권리 범위를 특정, CC 피아노 음원 크레딧 별도 |

## 실제 프로그램의 공개용 안전 조건

- 대상: `moa-signal`, `moa-space`, `moa-party`, `moa-breeze`, `beat-basic`, `beat-half`, `sixteenth`, `dotted` — 코드에 내장된 연습곡의 **원본 데이터와 동일**한 경우에만 공개용 제작 버튼 진입. 저작물 권리가 확인되었다는 뜻이 아님.
- 기존 동요, 다운로드한 악보, 가져온 곡, 내용 변경된 곡은 **공개용에서 기술적으로 차단**. 이들은 수업용 영상 녹화 버튼은 계속 사용 가능.
- 사용자가 불러온 MR 파일이 있으면 공개용 차단. 원본·가공·유료 여부를 자동 판단할 수 없으므로 기본 자동 반주만 허용.
- 아이 이름/자체 문구 등 식별 가능한 라벨이 나오지 않도록 표시 방식을 '계이름'으로 제한.
- 현재 선택한 곡의 저작권 확인 체크가 없으면 공개용 제작 중단. 곡 변경 시 체크 초기화.
- 공개용 영상은 인트로와 엔딩을 강제 포함(옵션을 껐더라도). 엔딩에는 원 피아노 녹음 저작자, CC BY 4.0, 소스 URL, 변경 사항과 비후원 문구 출력.
- 유튜브 설명문 복사 기능을 제공. 영상 전용 파일명에 `유튜브공개검토용` 표시. 유튜브 직접 게시 기능은 제공하지 않음.
- 외부 음원 계약, 제3자 작품 유사성, 상표·초상권 등을 자동 검사한다고 표시하지 않는다.

## 업로드 전 운영 체크

1. YBM 비교 영상 (https://youtu.be/C2cP86CAuGQ)의 영상 화면 구도·공 애니메이션·효과음·클립 길이·인트로/엔딩을 나란히 검토한다. 제품 분야의 공통된 색/기능과 고유한 표현을 구별한다. **자동으로 검증되지 않았음**.
2. 내장 창작곡의 노래 제목·주요 멜로디·가사·편곡이 기존 곡과 뚜렷이 일치하지 않는지 음악 담당자가 직접 확인하고 검토 날짜를 남긴다.
3. 유튜브 공개용 만들기 기능에서 적격한 내장 연습곡을 선택, MR 파일이 없음을 확인, '계이름' 표시, 권리 확인 체크 후 녹화한다.
4. 설명문 복사 → 영상 업로드 시 설명란에 붙여넣는다. CC BY 음원 크레딧은 **영상 엔딩과 설명문 모두** 유지한다. 공개 게시 영상이 아닌 경우에도 CC BY 이용 조건은 지켜야 한다.
5. 첫 영상은 YouTube Studio에서 비공개로 업로드하고 저작권 검사 결과·제한 내용을 확인한다. **이 결과는 법적 면책이 아님**. 문제가 있다면 바로 공개하지 않고 원인·권리를 검토한다.
6. Git 커밋/PR 기록, 1차 악보 작성일, 샘플음원 출처/라이선스, 영상 파일, 공개일, YBM 표현 비교 기록, 사용자 확인 기록을 보관한다.
7. 권리 주장이 들어오면 주장 주체와 주장된 구간/권리를 확인하고 먼저 영상의 해당 부분 수정 또는 음원 제거 등을 검토한다. 근거 없이 이의제기를 반복하지 않는다.

## 남은 미검증 영역 (공개 적합성 최종판정에 필요)

- YBM 링크 영상의 **실제 화면을 프레임별로 대조하는 표현 유사성 검토**는 완료하지 못했다.
- 네 내장 창작곡과 네 박자 연습곡에 대한 외부 음원 DB 및 기존 발매 음악과의 독립적인 악보/귀청 비교는 진행하지 못했다.
- 출원·등록된 관련 상표 또는 디자인권 침해 검토는 별도로 진행하지 못했다. 제3자의 브랜드 로고·채널 정체성을 차용하지 않는다.
- 최종 영상의 YouTube Studio 저작권 검사는 브라우저 내 버튼이 대신해 줄 수 없다.
